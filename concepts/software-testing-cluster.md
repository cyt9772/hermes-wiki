# 소프트웨어 테스팅 클러스터 (테스트 3권 비교)

2026-10-25 USB 8권 배치의 테스팅 3권 — **이론·과정 프레임(Patton) / 실무 기법(STA 6인) / 기업 프로세스(MS 현직 테스터 3인)** — 을 한 축으로 정리한 비교 페이지. 세 책은 모두 "완전한 테스트는 불가능하다"는 전제에서 출발하지만, 각각 (1) 테스터 개인의 학습 경로, (2) 조직의 테스팅 실무 체계, (3) 최상위 기업의 운영 프로세스라는 서로 다른 층위를 다룬다.

## 공통 축
1. **테스트 레벨의 단계성**: 세 책 모두 컴포넌트→통합→시스템(→인수)의 레벨 구조를 전제로 한다. Patton은 8장에서, STA는 2장에서, MS는 엔지니어링 라이프사이클(03장)에서 각각 동일한 축을 전개.
2. **리스크 기반 노력 배분**: "완벽한 테스트는 불가능"이라 공통으로, Patton은 3장 살충제 패러독스로, STA는 5.5절 리스크 기반 테스팅으로, MS는 07장 코드 복잡도 리스크로 — 같은 원리의 세 가지 실무화.
3. **정적/동적 구분**: Patton의 명세 검토(4장)·코드 리뷰(6장) = STA의 Part 3 정적 기법(리뷰) = MS의 04장 케이스 작성 전 단계. 정적 활동이 동적 테스트를 대체하지는 못하지만 비용을 절감한다는 합의.
4. **CMMI/프로세스 매핑**: 세 책의 프로세스(계획→설계→실행→리포팅)는 [[cmmi-process-maturity]]의 성숙도 프레임에서 "정의/관리 레벨"의 프로세스 영역과 구조적으로 대응 — 프로세스 품질 관점의 상위 개념.
5. **자동화의 위치**: Patton(개념) < STA(정적 분석 도구) < MS(조직 확산 사례). 기술 자체보다 "도입→도입 확산"의 실행 역량이 차별점.
