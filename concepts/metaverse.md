# 메타버스 (Metaverse)

> "또 하나의 나를 꿈꾸는 세상, '메타버스'" — [[seventech]] 8장 표제 (p190)
> 저자: 김상균 (강원대 문화예술공과대학 교수, 메타버스·게임 인류학)

## 정의
- 메타버스 = AR/VR(공간·감각 계층) + [[blockchain]](자산·소유 계층, NFT) + [[cloud-computing]](실행 환경) + [[iot]](입출력) 를 아우르는 **통합 디지털 세계**.
- "3년 후"의 핵심: 물리적 현실과 디지털 현실의 경계가 흐려지는 곳.

## 세븐 테크와의 관계
메타버스는 나머지 6개 기술의 **무대(Stage)**다:
- AR/VR → 사용자 인터페이스(입력·출력, 몰입)
- NFT/블록체인 → 디지털 자산 (공연 영상, 게임 아이템, IP)
- 클라우드 → 가상 공간 렌더링·동시접속 처리
- IoT/로봇 → 물리적 세계와의 연결 (버추얼-물리적 인터페이스)
- AI → NPC, 콘텐츠 자동 생성

## 본서 실사례
- **아리아나 그란데 × 포트나이트 가상 공연** (2021.8) (p199, OCR)
- **NFT 공연**: 공연 영상 분할 → NFT화 → 경매 (2021 AMEX 카드) — 카드 회원 대상 한정 NFT (p199–200)
- **버추얼 프로덕션**: 비브스튜디오스(Vivestudio)가 국내 최초 개발 (p2, 김세규 bio)
- **K-엔터의 메타버스**: "한국에서 메타버스에 대한 고민을 가장 많이 하는 기업이 엔터테인먼트·공연" (p199) — K-pop IP가 디지털 자산화가 되기 쉬운 구조
- **VR/AR의 역사**: "1980년대 시작, 30년 만에 빛을 봄" (p116, 정지훈) — 기술의 상용화 주기가 긴다는 관찰

## 투자 관점
- 2021–2022 기준 "메타버스" 테마의 한국 관점 해설.
- 추적 포인트 (위키 투자쪽에서 연결):
  - 게임사 (포트나이트 생태계, 모바일 게임사)
  - 버추얼 프로덕션·XR 하드웨어 (HMD, 센서)
  - 엔터 IP (K-pop, 음반/영상 디지털화)
  - NFT·Web3 결제·ID 인프라
- "현장 실재감 옹호" (p199, OCR) — 가상 공연의 한계 지적: **온라인·오프라인의 혼합(Phygital)**이 최종 승자일 수 있다는 암시.
