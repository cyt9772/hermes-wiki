# 돈의 시간가치 (Time Value of Money, PV/FV) — 금융공학

**"1년 전의 1억 원, 현재의 1억 원, 1년 후의 1억 원은 모두 가치가 다르다"** — 모든 금융상품 밸류에이션의 기본 전제. 이자(할인)를 매개로 시간을 가격으로 바꾸는 금융공학의 제로 단위

## 원문

> "금융공학을 공부하기 위해 많은 선수 지식이 필요하지는 않지만 꼭 알아야 하는 개념이 있습니다. 바로 돈의 시간가치(time value of money)입니다. 10년 전의 1억 원, 현재의 1억 원, 10년 후의 1억 원은 모두 가치가 다르지요. 이렇게 시간에 따라 돈의 가치가 달라지는 것을 돈의 시간가치라고 합니다." (Ch.2, p.29)

## 공식 (단순 경우)

- **미래가치** FV = 현재가치 × (1 + 이자율)
- **현재가치** PV = 미래가치 / (1 + 이자율)
- 예: 이자율 10%일 때, 10000원 예금 → 1년 후 11000원 (FV); 1년 후 10000원을 받기 위해 지금 9091원 저축 (PV)

## 파생상품 밸류에이션과의 연결

> "금융상품 밸류에이션의 기본 컨셉은 돈의 시간가치를 인정하는 것부터 시작합니다." (p.30)

- **선물 이론가** (F = S·e^(rT) − 배당·e^(rT)): "선물을 사면 기초자산을 확보하지만 후불(이자비용 절감)이지만, 배당권리는 못 받음" (p.173)
- **옵션 가격**(블랙-숄즈 C = S·N(d₁) − K·e^(−rT)·N(d₂)): "콜옵션 가격 = 기초자산의 기댓값 − 행사가격의 기댓값의 현재가치" (p.245) → 할인(할인률 r)이 옵션 가격의 핵심 요소
- **구조화 상품**: ETF/ELS/ETN 등 파생상품에 기반한 구조화 상품도 이 PV/FV 구조 위에 설계

## 실전 적용 (이 책에서)

1. **선물 포지션 손익 계산**(p.178~): 이론가 대비 시세 차이로 손익 추정
2. **옵션 가치 평가**(p.245~): 내재가치 + 시간가치 분해 (시간가치 = 옵션가격 − 내재가치, p.244-245)
3. **펀드/채권 할인**: 미래 현금흐름을 할인 → 현재가치로 평가
