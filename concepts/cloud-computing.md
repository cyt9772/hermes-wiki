# 클라우드 컴퓨팅 (Cloud)

> "독점이나 소유가 아닌 '공유'다." — [[seventech]] 7장 표제 (p168)
> 저자: 이한주 (클라우드 컴퓨팅 전문가)

## 정의
- **공유**가 핵심: 소유·독점이 아닌 사용과 공유의 경제 (p168)
- "기회의 신은 클라우드 안에 있으니" (p168) — 클라우드 = 세븐 테크의 **기반 계층 (Infrastructure)**

## 세븐 테크에서의 위치
클라우드는 나머지 6가지의 **지층** 역할을 한다:
- IoT/스마트폰/센서가 만든 **데이터를 저장**
- AI 학습·추론의 **연산 자원** 제공
- Web3·메타버스의 **실행 환경** (가상 공연, NFT 마켓, 게임 서버)
- 로봇·제조·금융의 **백오피스** 대체

## 본서의 핵심 구절
- "클라우드의 핵심 개념이자 기본은 **공유**다" (p168)
- "독점이나 소유가 아닌 공유" (p168)
- 클라우드 + AI + IoT = **데이터 문명 3총사** (서사 전체를 관통)
- 5G가 통신 지층이라면, 클라우드는 **저장+연산** 지층.

## 투자 관점
- 본서가 직접 다루지는 않는 구체 종목/포트폴리오 없음. (교양서 수준)
- 추적 포인트 (위키 투자쪽에서 연결):
  - IaaS (Azure, AWS, GCP, 알리클라우드 등)
  - SaaS / PaaS
  - 데이터 센터·쿨링·전력 (AI 데이터 센터의 물리적 자산)
  - 클라우드 네이티브 기업 (MSP, 컨설팅)
