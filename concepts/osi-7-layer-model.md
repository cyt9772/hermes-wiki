# OSI 7계층 모델

국제표준화기구(ISO)가 정한 네트워크 계층화 모델. 통신을 7가지 계층으로 나누어, 각 계층이 인접 계층에만 서비스를 제공하고(추상화) 동일한 계층끼리 프로토콜로 대화하게 함으로써 이종 시스템 간 호환성을 확보한다. 1990년대 한국 통신 교재 기준의 정립된 체계.

> "제 6 장 프로토콜과 OSI 계층 모델 … 6.2 OSI 계층 모델 / 205" `[raw/books/lan-van-isdn.md]` TOC p.6

## 7개의 계층 (하위→상위)
| # | 계층 | 역할 |
|---|------|------|
| 1 | 물리 계층 (Physical) | 비트(bit) 전달 — 신호·케이블·전송 매체 |
| 2 | 데이타 링크 계층 (Data Link) | 프레임, 오류 제어, 멀티프레임(데이타링크 제어) |
| 3 | 네트워크 계층 (Network) | 패킷 라우팅, 논리 주소, 인터네트워킹 |
| 4 | 트랜스포트 계층 (Transport) | 접속점 간 신뢰성, 재전송/순서 제어 (PDU) |
| 5 | 세션 계층 (Session) | 세션 설정·관리·종료 |
| 6 | 프리젠테이션 계층 (Presentation) | 데이터 형식·인코딩·암호화 표현 |
| 7 | 응용 계층 (Application) | 사용자 서비스 (전자우편·파티터미널 등) |

## 계층 모델의 의의
- **추상화**: 상위 계층은 하위의 구현 방식(매체·신호)을 몰라도 됨
- **호환성**: 동일 계층의 프로토콜만 정합하면 이종 망 상호 접속 가능 — 5장 인터네트워킹(브리지·X.75·IP)의 전제
- **프로토콜 정의**: 각 계층마다 PDU(프로토콜 데이타 유닛)와 서비스 정의 — LAN(7장)·VAN(8장)·ISDN(9장) 프로토콜 체계가 이 모델 위에 놓인다 `[raw/books/lan-van-isdn.md]` ch6, ch7, ch9

## 이 책에서의 적용
- 2장(데이타링크 제어·오류 제어) → 계층 1~2
- 3장(패킷 교환) → 계층 3
- 5장(인터네트워킹·브리지·X.75·IP) → 계층 2~3 경계와 네트워크 계층
- 6장 → 모델 전반의 정립
- 7장 LAN / 9장 ISDN → 1~4계층의 실제 체제
