# 신용 사이클

금리와 신용은 매우 밀접한 관계: 금리 → 대출 비용 → 대출 규모 → 신용 공급 → 경기 (PART 5).

## 메커니즘

- 금리 **인하** → 대출이자가 싸지 → 가계·기업 대출 증가 → 경기 확장.
- 신용 공급이 **자기 강화**되면(부동산·주식 가격 상승 → 담보가치 상승 → 대출 한도 확대) 버블 형성.
- 금리 **인상** + 신용 수축이 동시에 오면 → 대출 부실 → 경기 침체 → 금융위기 ( PART 2, 5 ).

## 금융위기의 구조

- 서브프라임 모기지 사태 (p242 TOC) — 금리인상으로 고정금리 모기지 상환부담 급증.
- 금융위기 핵심 7 키워드 ( p065 ) — 서문·PART 2에서 반복 등장.
- **재정긴축 vs 저금리** ( p085~092 ) — 위기 대응의 두 갈래.

## 투자 관점

- 신용수축 초기(부실 발견 초기) = 자산가격 저점 구간 (기회)
- 신용팽창 후기(모두가 레버리지) = 버블 정점 구간 (위험)
- "범인은 금리" 프레임 + 신용수준 = 위기 타이밍 판독
