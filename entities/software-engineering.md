# 소프트웨어공학론 (Software Engineering Principles)

**김태달** 저, 형설출판사 2004. 632쪽의 학부 교과서. "프로젝트 추진 현장에서 활용할 수 있는 소프트웨어공학 관련서"가 없다는 문제의식에서 집필 — 학부 과정에서 체계적으로, 산업 현장에서 바로 참고할 수 있는 것을 목표로 한 국내 SW공학 총론.

## 장 구성 (머리말 + 목차, 원문에 기초)
- 제1장 소프트웨어와 소프트웨어공학 — 정의·특성
- 제2장 프로젝트 관리 / 제3장 견적(노력정도 산정, 개발비용)
- 제4장 시스템 개발 프로세스(개발 모델 선정)
- 제5장 사용자 요구조사 / 제6장 시스템 분석과 설계
- 제7장 구조적 시스템 분석 / 제8장 구조적 시스템 설계 및 개발
- 제9장 사용자 인터페이스 설계 / 제10장 화일 설계 / 제11장 데이터베이스 설계
- 제12장 객체지향 분석·설계·개발 / 제13장 실시간 시스템 / 제14장 정보공학 방법론
- 제15장 소프트웨어 재사용 / 제16장 컴포넌트 소프트웨어 / 제17장 소프트웨어 리엔지니어링
- 제18장 소프트웨어 시험(테스트 원리·화이트박스·블랙박스·자료구조 중심·통합·인수)
- 제19장 유지보수 / 제20장 소프트웨어 품질보증(평가 매트릭스, V&V, walkthrough/inspection, SQA 정형 접근, 신뢰성)
- 제21장 외주관리 / 제22장 소프트웨어 형상관리(개념·표준)

## 핵심 3~5개
1. **전 주기 총론의 구조**: 요구조사→분석·설계→시험→유지보수→외주관리까지 22장으로 소프트웨어 공학의 거의 모든 주제를 단일 교과서로 통합 — 국내 학부 교육용 총론의 표준 형태 `[raw/books/software-engineering.md]`
2. **구조적 기법 축**: 7·8장에서 구조적 분석/설계(자료 흐름도·처리·자료 설계)를 중심 기술로 다룸 — 1990년대 구조적 기법 시대의 공학론.
3. **품질보증의 정형 접근**: 20장에서 V&V, 검토회(walkthrough)와 검열(inspection), 품질 매트릭스, SQA 정형 접근을 교재화 — CMM 계열 프로세스 품질관리의 국내 교재적 대응.
4. **OO/컴포넌트/리엔지니어링**: 12·16·17장에서 객체지향·컴포넌트 기반 개발·리엔지니어링을 병치 — 절차적 구조 중심 교과서가 OO·컴포넌트 시대로 확장되는 과도기 서적.
