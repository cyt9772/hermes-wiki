# 사물인터넷(IoT)을 위한 리눅스 프로그래밍 (개정판)

> 저자: 서영진
> 국내서(리눅스 프로그래밍 실용 시리즈) | 제이펍, 2020
> 941p `raw/books/raspberry-pi4-iot-linux.md`

## 개요
라즈베리파이(PI 3/4)를 중심으로 **IoT·리눅스 프로그래밍·딥러닝/컴퓨터 비전**까지 다루는 1,200쪽급 종합 서적. 1부에서 보드와 주변장치 소개에 이어, 2부에서 리눅스 사용 환경(셸·명령어·vi·프로그래밍 도구)을 다고(제1-5장), 3부에서 Python으로 GPIO/SenseHAT 제어(제3장), 4부에서 C 언어로 파일/프로세스/소켓(제4-6장), 7-9부에서 웹 서버·WebSocket·딥러닝(오픈CV·텐서플라)으로 넘어가며 최종부에서 종합 프로젝트까지 `raw/books/raspberry-pi4-iot-linux.md`.

## 특징
- 1,200쪽 분량 — IoT에서 AI/딥러닝까지 폭을 한권에 담음
- 리눅스 프로그래밍 실용 시리즈의 "최상위 종합서"
- Python(3부) - C(4-6부) - Web(7-8부) - AI(9부) 순 언어/기술 전환
- 딥러닝(오픈CV·텐서플라)까지 다루어 IoT 실습의 최상위 확장
