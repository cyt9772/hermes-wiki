# 생애재무설계 지금 당장 시작하라

**삼성경제연구소 (SERI) 출간 (2011년 3월 31일 초판 1쇄), 저자 홍은주.** "지금 당장 시작하라"는 타이틀이 핵심 메시지인 생애 재무설계 교양서.

## 한 줄 요약

> 장수리스크 시대의 한국인에게 **65세 이후부터 역산한 3단계 설계**와 **황금법칙(72의 법칙·100-나이·적립식)**을 적용해 노후자금을 만드는 실전 교본.

## 구조 (7장)

| 장 | 주제 | 핵심 제안 |
|---|---|---|
| 1장 | 현대판 델파이의 신탁: 저출산–고령화 | 장수리스크 · 메디컬 푸어 · '요람서 무덤까지' 불패 신화의 종언 |
| 2장 | 생애재무설계의 이해 | 계획성 · 장기성 · 합리성. 재테크 ≠ 재무설계. 4대 기본목표 (p49) |
| 3장 | 재무설계를 위한 금융투자 황금법칙 | 파레토·손절매·적립식·**100-나이 (p70)**·**72의 법칙 (p71)**·분산투자 (p79) |
| 4장 | 위험도에 따른 금융상품 선택법 | 분할매매형·라이프사이클 펀드 (p94-95) · 랩 어카운트 (p96) · 보험설계 |

| 6장 | 연금설계의 3층 구조 | 국민연금·퇴직연금·개인연금 (p126-139) · ISA (p140) · **역모기지·숨어 있는 2% (p142-144)** |
| 7장 | 생애재무설계의 실제 | **3단계 역산 (p146-155)** · 20·30·40대 설계 (p156-163) · 결론 (p164-165) |

## 투자 관점

- **7장에서 제시하는 3단계는 목표 역산(goal-based) 프레임**. 65세 이후의 노후자금부터 → 40세 현재가치 → 은퇴 후 현금흐름, 순서대로 역산. "65세 이후가 가장 불안감이 [ ] 요가 많기 때문에 65세 이후의 자금 수요부터 미리 추정하고" (p146).
- **72의 법칙 = 72 ÷ 이자율 = 원금 배가 기간** (p71). "이자 8%를 주는 금융기관에 1억 [ ] 맡긴다면 복리의 [ ] 2억 원이 되는 시간은 72>8=9, = 9년이 걸린다" (p71). 저금리 시대 장기투자 (10년+)의 근거.
- **100-나이의 법칙** = 위험자산 비중 (p70). 30세 → 주식 70%; 은퇴 목전 → 예금·적금·채권 중심 40-50%.
- **적립식 분기매입**은 주가 하락 시 매입단가 하락으로 오히려 수익률 높임 (p68-69). "2008년 리먼 사태 이후 [ ] 해약했다. 그러나 [ ] 2010년 들어서면서 [ ] 주가는 천정부지로 [ ] 시작했다" (p69).
- **역모기지** = 숨어 있는 2% (p144). "연금 수령액은 집값이 비싸고 나이가 많을수록 높아지도록 설계되어 있고" (p143). 부부 한쪽 사망 시 연금액이 절반이 아니라 [ ] 유지 — 장수할수록 유리 (p144).
- **신용관리** = "가장 중요한 자산이 바로 신용이다" (p114). 주거래 은행 집중, 고금리 대부 조회 금지 (p116-117).
- **사오정·오륙도 (p119)**: 55세 퇴직 → 65세 국민연금까지 10년 공백. "퇴직금을 연금 방식으로 설계하는 것"이 연결소득의 핵심 (p119).
