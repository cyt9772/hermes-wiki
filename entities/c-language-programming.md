# C언어와 프로그래밍

> 표 2: '관용어와 라이브러리를 중심으로 한 C언어와 프로그래밍' (p2)

## 개요
- **저자/역자:** Eric S. Roberts 저, 김정선·도경구·박성주·오희국·최중민 역 (p2)
- **출판:** 교보문고 / Addison-Wesley Publishing Company (p1, p2)
- **성격:** 전산학(cs) 기초와 C 프로그래밍을 함께 다루는 입문 교재, PDF 825쪽. '관용어와 라이브러리를 중심으로' C를 가르침 (p2).

## 내용
- 저자 서문 — 스탠포드대 전산학과 부학과장, 1980년 박사학위 이후 하버드·웰리슬리·스탠포드에서 전산학 강의, 1990년부터 CPSR 회장에 '전산학을 시작하려는 학생들에게 컴퓨터의 무한한 힘에 눈을 뜰 수 있도록' (p4).
- 학생에 대한 환영 — '환영합니다. 이 책을 선택함으로써 여러분은 … 전산학의 세계로 한걸음 다가갔습니다' (p5).
- 인터페이스 설계 연습문제 — 동전 던지기 시뮬레이션: '\It took 10 flips to get heads 3 consecutive times.' (p364).
- 다트판(dart board) 시뮬레이션으로 상수 π 근사값 구하는 난수(랜덤) 사용 예제 — 다트의 면적 비율이 원·정사각형 면적 비율과 일치함을 이용 (p364).
- 재귀 알고리즘: 문자열의 모든 순열 — '길이가 n인 문자열의 모든 순열을 표시하기 위해서는 … 남아 있는 n-1개의 문자의 순열을 위치시키면 된다'와 `PermuteWithFixedPrefix` 프로시저 (p727).
