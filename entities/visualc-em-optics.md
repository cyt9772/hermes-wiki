# C++ 6.0 으로 구현하는 정전기학·기하광학 (Choi Haeng-jin 2001)

> 저자: **최행진** (Choi Haeng-jin)
> 출판: 내하출판사, 발행인 모흥숙, 2001-11-10, ISBN 89-88932-25-0, 336p, 정가 13,000원
> 저자서문: "…전자기학의 한 분야인 **정전기학 (electrostatics)**과 광학의 한 분야인 **기하광학 (geometrical optics)**을 대상으로 한다."

## 개요
**C++ 6.0 + MFC**로 물리현상을 시각화·시뮬레이션하는 실무서. **MFC 개요(제0장)** → **전자기학 기본(제1장: 정전기학, Helmholtz 정리, 전계의 분류 1-4종)** → **등전위선·전기력선(제2장: 점전하, 쌍전하, 구면전하, 쌍극자, 사중극자, 도체구, 유전체구)** → **전기다중극(제3장: 스칼라 퍼텐셜의 다중극 전개)** → **영상법(제4장)** → **변수분리법(제5장)** → **빛의 반사·거울(제7장)** → **빛의 굴절·렌즈(제8장)** → **3차원 입체 구현(제9장)** → **입체 확대·축소(제10장) / 회전(제11장) / 숨은선·면(제12장)** → **이변수함수 그래프(제13장)** `[raw/books/visualc-em-optics.md]`.
