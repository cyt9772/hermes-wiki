# 프로젝트로 배우는 라즈베리 파이

> 저자: 도날드 노리스(Donald Norris) | 역자: 임지순
> 원서: Raspberry Pi Projects for the Evil Genius, 1st Ed. (McGraw-Hill, 2013) | 한빛미디어 (McGraw-Hill Korea 공판), 2015
> 340p `raw/books/raspberry-pi-projects.md`

## 개요
"Evil Genius" 시리즈의 라즈베리파이 편 — **LED 깜빡이기에서 MP3 플레이어·GPS·홈 시큐리티·NFC/RFID 리더까지 10여 개의 보드 프로젝트를 단계별로 구현**하는 실습서. 각 프로젝트가 하드웨어(BOM·배선) - 소프트웨어 - 테스트 - 마무리의 4단으로 구성 `raw/books/raspberry-pi-projects.md`.

## 장 구조 (15 프로젝트)
| 장 | 프로젝트 |
|----|------|
| 1 | 라즈베리 파이의 소개 (보드·OS·연결) |
| 2 | LED 깜빡이기 |
| 3 | MP3 플레이어 |
| 5 | GPS (위치 추적) |
| 8 | 홈 시큐리티 컨트롤러 |
| 9 | NFC/RFID 리더 |
| ... | (적외선, 모터, 웹 등 추가 프로젝트) |

## 특징
- **프로젝트 단위 구성** — 장이 곧 프로젝트(보완 BOM·배선도·코딩·테스트 포함)
- "Evil Genius" 시리즈 특유의 단계별 실습 스타일
- 하드웨어 + 소프트웨어 병행 — SBC 입문의 대표 미국 서적
