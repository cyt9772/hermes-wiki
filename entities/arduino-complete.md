# 아두이노 완전정복

> 저자: 김경연
> 국내서 | JK전자(복두출판사), 2015
> 288p `raw/books/arduino-complete.md`

## 개요
Arduino UNO R3 + 스타터 키트로 **전기·전자 기초 → 디지털/아날로그 입출력 → 시리얼(RS232) → 센서(CDS/DHT11/화염) → 네트워크(이더넷/지그비/블루투스) → IoT·스마트홈 프로토타입**까지 실습하는 국내 입문 실무서. 센서·입출력 장치 중심으로 하드웨어와 코드를 동시에 다룸 `raw/books/arduino-complete.md`.

| 장 | 제목 |

| 3 | 디지털 입력과 출력 (LED·7세그먼트·버저) |

## 특징
- 전기·전자 기초(2장)를 먼저 다룸 — 저항·LED·브래드보드·테스터기
- 센서(7장)와 통신(10-12장: IR·지그비·블루투스)을 IoT 관점으로 연결
- 스코치 코드를 JK전자·디바이스샵에서 다운로드하는 실습 중심 구성
