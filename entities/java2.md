# Java 2

> 객체지향 개념부터 쓰레드, AWT, 그래픽, 오디오, 애플릿, 스윙, 데이터베이스까지 단계별로 차근차근 설명한 해설서 (p1)
## 개요
- **저자:** 김성진 (공학박사)
- **쪽수:** 726p (OCR 추출, 로컬 PDF `/run/media/yutae/Data/Java 2.pdf`)
- **위치화:** 2000년대 초 초보~중급 독자를 위한 자바 입문 해설서. '자바는 이제 단순히 웹 브라우저에서 재미로 보여지는 기술이 아닙니다… 놀라운 기술이 되고 있습니다' (p4).
## 내용
- '바야흐로 세상은 네트워크의 세상입니다' — 웹·무선·DB·가전까지 적용이 가능한 미래지향 기술로 자바를 제시 (p4).
- 기본 데이터형 외에 레퍼런스 데이터형: '기타 언어의 포인터와 비슷한 기능을 갖고 있다'고 보이지만, C 포인터가 메모리에 직접 접근하는 반면 '자바의 레퍼런스 데이터형은 그렇게 할 수 없다는 점에 차이가 있다. (이것이 자바가 안전한 이유 중의 하나이다.)' (p55).
- 변수 선언: '자바에서는 모든 실행문의 뒤에 세미콜론(:)을 붙여야 한다. 이것은 컴파일러에게 실행문이 완결되었음을 알려주는 역할' — 컴파일 에러 대다수가 세미콜론 누락에서 온다는 실무 팁 (p56).
