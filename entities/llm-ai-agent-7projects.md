# 7가지 프로젝트로 배우는 LLM AI 에이전트 개발

**원저:** 大模型应用实战: 亲手做 AI Agent by 黄佳 (Posts and Telecom Press 2024, ISBN 9787115642172)
**한국어판:** 黄佳(황자) 지음 / 김진호 옮김, **제이펍** 1판 2025-04-22, ISBN 979-11-94587-20-0, 437p

> "인공지능은 Life 3.0으로 가는 열쇠입니다." — 1장, 테그마크 *Life 3.0* 인용

## 구성 (11장 / 프로젝트 7개 포함)
1. 에이전트란 무엇이며, 왜 에이전트인가 — Life 3.0, 가트너 8대 예측, AaaS, 자기 진화형 AI (p3)
2. LLM 기반 에이전트 기술 체계 — 4대 핵심요소(의사결정·기억·도구·계획), ReAct·CoT·ToT (p47)
3. OpenAI API · LangChain · LlamaIndex (p81)
4. **프로젝트1** 자동 오피스 — Assistants API + DALL·E3로 PPT (p132)
5. **프로젝트2** 다기능 선택엔진 — 함수 호출 (p193)
6. **프로젝트3** 추론-행동 협업 — LangChain ReAct, 자동 가격설정(꽃) (p246)
7. **프로젝트4** 계획-실행 분리 — 스마트 스케줄러(물류·재고) (p282)
8. **프로젝트5** 지식 추출-통합 — LlamaIndex RAG, 재무보고서 (p311)
9. **프로젝트6** GitHub 인기 에이전트 — AutoGPT · BabyAGI · CAMEL (p329)
10. **프로젝트7** 멀티 에이전트 — AutoGen · MetaGPT (p375)
11. 다음 세대 에이전트: 학술 논문 (p397)

## 위치 (4권 내 차별점)
- **7개 실습 프로젝트**로 구성 — 4권 중 "프로젝트 수"가 가장 많고 AutoGPT/CAMEL/MetaGPT 등 **오픈소스 멀티에이전트 프레임워크**를 구체적으로 다룸.
- 원저가 **중국서(黄佳)** → 한국어 번역.
- "왜 에이전트인가" 철학(Intro) + "어떻게 만들지"(프로젝트) 균형.
