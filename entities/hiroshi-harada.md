# Hiroshi Harada (하라다 히로시)

일본의 무선·이동통신 시스템 학자. MIMO·OFDM·OFDMA·단대역 정합 필터(DFC)·채널 부호화·채널 추정 분야에 걸쳐 수십 권의 저서를 집필한 이동통신 시스템 설계의 대가.

## 주요 저작 (이 2권 외 참고 — 원서 목록 기반)
- *Mobile Communication Systems: Software Radio to OFDM* — 이동통신을 소프트웨어 무선에서 OFDM으로 이끄는 대표서
- *Mobile Communications using MATLAB Simulation* (Artech House, 2002)
- *MIMO-OFDM Wireless Communications with MATLAB* (Artech House, 2011)

## 연구 축
- 채널 모델링·추정 (SISO/MIMO)
- OFDM/OFDMA 시스템 설계
- 시공간 부호(STBC, Alamouti)
- 채널 적응형 전송, 빔포밍
- MATLAB 기반 시뮬레이션 (이 2권의 공통 방법론)
