# 이것이 코딩 테스트다 with 파이썬

> 포지셔닝: "취업과 이직을 결정하는 알고리즘 인터뷰 완벽 가이드" (p1)

## 개요
- **Author:** 나동빈 저
- **Publisher:** 한빛미디어
- **Pages:** 599
- **Positioning:** 파이썬으로 풀어 보는 취업·이직용 코딩 테스트(알고리즘) 완벽 가이드. 2020년 1쇄(C/C++, 자바 기출문제 포함, 유튜브 강의·코드 제공) (p1).

## 내용
- 지은이의 글: "수학을 어려워하던 문과생이 컴퓨터교육과에 진학한 게 모든 일의 시작이었습니다" / "특히 어려운 알고리즘 문제에 막혀서 결국 불합격" (p5).
- PART 01: "코딩 테스트 개념과 배경 · 실습환경 구축하기 · 복잡도"와 2016~20년 기출 유형 분석 (p16).
- PART 02 주요 알고리즘: "CHAPTER 03 그리디 — 실전문제 큰수의 법칙" (p16).
- 탐색: "CHAPTER 05 DFS/BFS — 실전문제 음료수 얼려 먹기 · 미로 탈출" (p17).
- DP/최단경로: "CHAPTER 08 다이나믹 프로그래밍"·"CHAPTER 09 최단 경로" 등 이론+실전 문제 체계 (p17).
