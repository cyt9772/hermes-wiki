# 전자공학입문 (국가기술자격검정시험연구회 편)

> 저자: 국가기술자격검정시험연구회 편 — 단체 저자(단발성)라 엔티티 미생성
> 출판: 학당(학문당), 573p — 통신공사·전자직국가공무원·일반기업체 채용시험 대비
> 서문: 『신전자공학』과 자매서(같은 출판사·같은 서문 도입부). "새로운 교육과정에 의거 반도체소자·연산증폭기·논리회로를 바탕"

## 개요
**국가기술자격검정시험+전자직 공무원+통신공사직 채용시험 대비 전자공학 입문 수험서**. 전자(진공관) → 반도체소자 → 전원 → 증폭 → 연산증폭 → 발진 → 변복조 → 펄스 → **논리회로** → 집적회로 순서로 전개되며, **논리회로(10장)까지 포함**한다는 점에서 같은 출판사 자매서인 『신전자공학』보다 범위가 더 넓다. 각 장에 "주관식 문제 + 출제경향예상문제". `^[raw/books/intro-electronics.md]`

## 장 구조 (11장 + 부록, 573p)
1. **전자** — 전자기학 기초(전기장/자기장 중 전자 운동), 전자 방출(일함수·열전자·광전자·2차·고전장), 전자 빔(광전자 렌즈), 진공관(2극·3극·4극·5극), 특수관(방전관·브라운관·광전관)
2. **반도체소자** — 반도체 성질(에너지대·진성/불순물·홀 효과), 다이오드(PN 접합·정류·종류), 트랜지스터(발달·동작원리·종류), FET(접합형·MOS형), 반도체 스위칭 소자(PNPN·SCR·다이액·트라이액·단일접합 트랜지스터), 그 외(제너·터널·더에미스터·바리스터·가변용량·광전변환)
3. **전원회로** — 정류(반파·전파·제너), 평활(유동성·용량성·LC·피형), 제어 정류, 정전압 전원(병렬/직렬 제어)
4. **증폭회로** — 트랜지스터 동특성·바이어스·증폭도·일그러짐·잡음, T형/h형 등가, 접지 방식(이미터 접지·이미터 플로터)
5. **그 밖에 증폭회로** — 되먹임(전압/전류), 전력증폭(A급·푸시풀), FET 증폭, 주파수 응답(저주파·고주파·동조)
6. **연산증폭기** — 특성·차동·직류 연산(부호전환·덧셈·고입력저항·미분/적분·가변표준전원)
7. **발진회로** — LC(하아틀리·콜피츠), 수정(진동자), RC(이상형·브리지형), 초고주파(마그네트론·클라이스트론)
8. **변·복조회로** — 진폭 변조/복조, 주파수 변조/복조
9. **펄스회로** — 미분/적분, 클리핑·클램핑, 멀티바이브레이터·블로킹 발진·톱날파
10. **논리회로** — 2진수 연산·보수·코딩·스위칭이론·부울대수, 기본 논리(AND·OR·NOT·NAND·NOR·XOR), 전자 논리 회로(DTL·TTL·MOS), 조합 논리(반가산자·전가산자·해독기·멀티플렉서·부호기), 기억장치(RS-FF·시각 RS-FF·D-FF·JK-FF), D/A·A/D 변환기
11. **집적회로** — 발달과 특징, 반도체 IC 제조 공정(에피택셜 성장·분리 확산·베이스·이미터 확산·알루미늄 증착·조립), 모누시 모나리스 IC(원리·예)
+ **부록 1** — 측정기, 전자재료 부품 표시 방법
+ **부록 2** — 물리량 단위, 기본 상수, 주기율표, 반도체 회로기호, 일반 트랜지스터·FET 특성표

## 핵심 기여 / 학습 포인트
- **아날로그 + 디지털 논리회로(10장)를 한 책에** — 같은 출판사 자매서 『신전자공학』 대비 디지털 논리/기억장치·D/A·A/D까지 포함
- **초고주파 발진기(마그네트론·클라이스트론)** — 수험서 중 드문 초고주파(10-15GHz) 발진관 내용
- **집적회로 제조 공정(11장)** — 에피택셜 성장·분리 확산·알루미늄 증착 단계별로 서술
- **부록 특성표** — "일반 트랜지스터 특성", "일반 FET 특성" 실측/표 기준값 수록
