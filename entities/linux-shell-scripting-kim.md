# 김태용의 쉘 스크립트 프로그래밍

> 저자: 김태용 지음 (안광선 감수). 제이펍(주), ISBN 978-89-962410-2-7, 초판 2009-09, 5쇄 2012-06, 703쪽 `[raw/books/linux-shell-scripting-kim.md]`

한국리눅스유저그룹 회장 김태용이 실무 운영 경험을 바탕으로 쓴 **리눅스 쉘 스크립팅 입문서**. 경북대학교 컴퓨터공학과 안광선 교수가 감수. 추천서(정경채, 김기종, 정왕부, 박종호)는 "리눅스 사용하면서 가장 중요한 것 중 하나가 바로 쉘 스크립트"이며 "서버관리자 필수"라는 평 `[raw/books/linux-shell-scripting-kim.md]`.

## 구조 (TOC, 8장)
| 장 | 테마 |
|----|------|
| 1 | 리눅스 쉘과 명령 기초 |
| 2 | 쉘 스크립트 맛보기 |
| 3 | 정규표현식·패턴 검색 |

| 6 | awk |
| 7 | bash |

## 특징
- **정규표현식 → grep/sed/awk 단일 도구 3부대** 중심. 3장의 정규식 개념이 4-6장 각 도구의 "왜 그렇게 동작하는지"를 설명하는 축으로 기능 `[raw/books/linux-shell-scripting-kim.md]`
- 7장 bash는 스크립트 언어 본령(변수·조건·반복·함수·함수 호출), 8장은 vi 편집기와 일반 유틸리티를 실무 마무리로 배치
- 703쪽 분량이지만 "각 도구를 1장씩 집중" 하는 밀도 조절 — grep/sed/awk 각 30-60쪽 대역의 심도, bash 100쪽 대역의 실습
- **한국 리눅스 커뮤니티 첫 세대(정경채·정왕부·김태용)가 서로 추천서에 등장**하는 커뮤니티 자서전적 성격 — "외골수"라는 표현으로 리눅스 확산 열정을 전하는 추천사 `[raw/books/linux-shell-scripting-kim.md]`
