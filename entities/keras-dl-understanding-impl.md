# Keras 기반 딥러닝의 이해와 구현

> 표지: '파이썬과 Keras로 이해하는 친절한 딥러닝 원리 학습과 활용' (p2)

## 개요
- **저자:** 임베디드 전문가 그룹 윌텍 저 (제3.02판) — 공인 강사 정호재·길성호·송화정 등, 삼성전자·성균관대·국제대 출강 이력 (p2, p3)
- **성격:** 실무역량(Lv.2) 교육용 교재. 머신러닝/딥러닝 개요에서 출발해 Keras의 원리와 구현을 함께 다룬다 (p2, p4).

## 내용
- 구조(차례, p4~5): 1부 ML/DL 개요 → 3부 딥러닝 기본(Multi Layer Perceptron p105, MNIST Dataset and Keras p123) → 4부 CNN(개요 p149, 기본 연산 p158, Classification p183, 발전시키기 p201) → 5부 RNN(Time Series Forecasting p255, RNN Models p266).
- MLP→MNIST(CNN)→RNN 순서로 신경망 아키텍처를 확장하는 전형적인 딥러닝 커리큘럼을 Keras 코드로 처리 (p4~5).
- '이해와 구현' 병행 철학: 원리 설명과 Keras/Python 실습 코드(예: MNIST 데이터셋 로딩과 모델 구성)가 각 과(과) 단위로 짝을 이룬다 (p4~5).
