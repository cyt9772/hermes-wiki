# 파이썬과 케라스로 배우는 강화학습

> 부록: '1부 "강화학습 소개"에서는 강화학습의 개론적인 이야기와 간단한 예를 통해 강화학습을 소개합니다' (p28)

## 개요
- **저자:** 이웅원, 양혁렬, 박건우, 이영무, 이의령 지음 (p1)
- **성격:** DS 데이터사이언스 시리즈. '내 손으로 직접 구현하는 게임 인공지능'을 표지로 내세우며, 파이썬 + 케라스 코드로 강화학습(RL)을 학습하는 실전서 (p1). PDF 374쪽.

## 내용
- 3부 구성: 1부 '강화학습 소개'(개론 + 간단 예제) → 2부 '강화학습 기초'(RL의 기반이 되는 이론과 수식) → 3부 '강화학습 심화'(그리드월드를 변형해 기존 강화학습을 확장) (p28~29).
- 1장 '강화학습 개요'에서는 강화학습이 무엇인지, 어떤 종류가 있으며, 강화학습이 적용된 사례를 통해 컴퓨터가 학습하는 전체 과정을 다룬다 (p28).
- 게임 AI(보드 게임·그리드월드)를 중심으로 정책·가치 함수 학습을 케라스 신경망으로 구현하는 방향 (p28~29).
