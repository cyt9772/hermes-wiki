# 비주얼 C++ 2.0 Object-Oriented Programming

> 비주얼 C++ 2.0 MFC(Microsoft Foundation Class) 프로그래밍을 위한 기본서 (p1)
## 개요
- **저자:** 전병선 (Microsoft 공인 강사)
- **쪽수:** 493p (텍스트 레이어 추출, 로컬 PDF `/run/media/yutae/Data/Object Oriented Programming.pdf`)
- **위치화:** 1995년 삼양출판사 발행. 'Object-Oriented 프로그래밍 개념과 C++ 언어에 대한 기본적인 설명' — 32비트 Windows 전환기 MFC 기본서 (p1).
## 내용
- 시대 배경: '이번에는 이것을 고민할 시간조차 없다. 이미 32 비트 윈도우즈용 비주얼 C++ 2.0은 발표되었고' — OLE2·네트워킹까지 포함해 '마이크로소프트사가 현재를 Object-Oriented Programming 시대로' 규정 (p5).
- 함수 호출 3법: '두 변수의 값을 바꾸는 다음 코드를 실행해 보면서, 이러한 세가지 함수 호출 방법을 비교해 보기 바란다' — [Call-by-Value]·[Call-by-Pointer]·[Call-by-Reference] swap 예 (p100).
- 저자: '국내 최초로 미국 마이크로소프트사가 인증하는 MFC·비주얼 베이직 MCT(Microsoft Certified Trainer) 자격을 취득' (p4).
