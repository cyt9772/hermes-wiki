# 이형배의 Java2

> 메소드(Method)를 우리 말로는 '방법'이라고 번역하는데, 클래스가 가진 기능이나 동작의 의미로 해석하는 것이 이해하기 쉽습니다 (p73)
## 개요
- **저자:** 이형배
- **쪽수:** 1212p (OCR 추출, 로컬 PDF `/run/media/yutae/Data/이형배의 Java2.pdf`)
- **위치화:** 한글 Windows 98/2000 기준으로 '이 책을 덮는 순간 난 Java 프로그래밍 전문가'를 내건 초보자용 자바 교과서. 많은 화면·삽화 삽입 (p4).
## 내용
- '이해되지 않는 것을 추구하는 자세는 좋으나, 시작부터 전부를 이해하려고 하면 도중에 지쳐버립니다' — '진행하는 동안 저절로 이해할 수 있게 된다'는 단계 학습법 (p74).
- 세미콜론 규칙: 'Java는 하나의 명령을 종료할 때는 반드시 문의 끝에 ;(세미콜론)를 붙인다' — '이 명령을 여기까지로 끝냄니다'를 컴파일러에 전하기 위함 (p73).
- 클래스명·파일명 규칙: 'Java 언어에서는 통상 클래스명의 처음 한 문자를 대문자로 하므로' 이름이 `Welcome`로 되어 있고, 파일명 `Welcome.java`와 처음이 일치 (p74).
