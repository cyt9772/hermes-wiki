# 챗GPT로 만드는 주식 & 암호화폐 자동매매 시스템

> 코딩을 몰라도 누구나 할 수 있는 파이썬 금융 프로그래밍 (p1~p2)

## 개요
- **저자:** 설근민 (p3)
- **출판:** 제이펍(주), 1판 1쇄 2023-11-17, 237쪽, ISBN 979-11-92987-03-3 (p3)
- **성격:** 챗GPT를 코딩 파트너로 삼아 주식·암호화폐 자동매매 시스템을 만드는 초보용 실습서. 독자 카페 https://cafe.naver.com/aiprograming (p5).

## 내용
- 전제: "코딩을 몰라도 누구나 할 수 있다" — 챗GPT가 쓴 파이썬 금융 프로그램을 만들고 실행하는 과정 (p1~p2).
- 챗GPT 질문법으로 금융 데이터 수집: 주식 데이터 수집 목표·질문 구성, "챗GPT 답변의 오류수정", 최종 데이터 확인 (목차 p5).
- 금융 데이터 분석: 텐서플로, 상관계수·변동성 분석, 주식/암호화폐 가격 예측모델 만들기 (목차 p6).
- 종목 추천 시스템과 자동매매 시스템: 증권사 API(목차 157쪽), 업비트 API 사용방법(목차 193쪽)으로 암호화폐 자동매매까지, 모두 EXE 실행 파일로 포장 (목차 p7~p8).
- 실전 데이터 병합 예: OHLCV 데이터와 재무 데이터를 `pd.concat`으로 병합 (p77).
- 출판사 면책: "운용 결과에 대해 지은이·제이펍 출판사는 일체의 책임을 지지 않음" (p5).
