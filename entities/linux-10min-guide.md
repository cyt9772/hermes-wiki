# 리눅스 10분 가이드

> 저자: 오주일
> 국내서 | 인포북, 2011
> 218p `raw/books/linux-10min-guide.md`

## 개요
"10분"이라는 제목 그대로 **리눅스 실습의 핵심만 빠르게** 다루는 입문서. 기본 명령 - bash 셸 - 프로그램 개발 환경 - 네트워킹 - X Window - 시스템 관리 - 기타 부록의 9장 체제로, 읽는 시간의 압축과 실습 중심에 초점이 맞춰져 있다 `raw/books/linux-10min-guide.md`.

## 장 구조 (9장)
| 장 | 제목 |
|----|------|
| 1 | 시작하기 (리눅스 소개) |
| 2 | 둘러보기 |
| 3 | 기본 명령 |
| 4 | bash |
| 5 | 프로그램 개발 환경 |
| 6 | 네트워킹 |
| 7 | X Window |
| 8 | 시스템 관리 |
| 9 | 기타 |

`raw/books/linux-10min-guide.md`

## 특징
- 218p로 얇아 **입문 첫 책**으로 적합
- bash(4장)와 X Window(7장)를 별도 장으로 처리
- "명령 - 셸 - 개발 - 네트워크 - GUI - 관리"의 최소 실습 곡선
