# 데이터 분석가 with ChatGPT

> "누구나 프로처럼, 월 20달러로 고용하는 데이터 분석가 — 코드 한 줄 없이 기초 통계부터 분석까지" (p1)

## 개요
- **저자:** 김진형, 이대복 (Copyright © 2024 김진형, 이대복 & 한빛미디어) (p3)
- **출판:** 한빛미디어, 초판 1쇄 2024년 10월 29일, ISBN 979-11-6921-297-7, 정가 93,000원 (p3)
- **쪽수:** PDF 513쪽
- **성격:** 코딩 없는 AI 활용 데이터 분석 실무서. '김대리'와 '박차장' 대화 형식으로 기초 통계 → 전처리 → 고급 분석·시각화까지 ChatGPT 활용법을 다룸. 입문~실무

## 내용
- 구성 철학: "지금까지 고급 데이터 분석과 시각화까지 한 단계씩 나아가는 김대리를 통해 실무에서 (ChatGPT를) 활용"하는 것을 목표로 대화형 서술 (p5).
- 이상치 정의: "이상치는 쉽게 말하면 데이터 분포에서 벗어난 극단적인 값을 뜻해요. 결측값과 마찬가지로 입력 오류일 수도 있고, 실제 데이터지만 매우 드문 조건으로 발생한 데이터일 수도 있죠" (p256).
- 이상치 확인 2가지 방법 중 하나: "박스 플롯 등을 활용해서 데이터를 시각화하는 방법 — 박스 플롯은 데이터의 상한선과 하한선에 따라 이상치를 분리해서 표시합니다" (p256).
- IQR 기준 판정: "IQR(Inter-quartile Range)을 이용해 데이터의 상한선과 하한선을 (최댓값 = Q3 + 1.5×IQR, 최솟값 = Q1 - 1.5×IQR) 나타내고, 이 값을 벗어나는 데이터를 이상치로 보죠" (p256-257).
- 이상치의 문제점: "분포를 벗어난 극단적인 값이기 때문에 전체 데이터 특성을 나타내는 통계값이나 알고리즘에 큰 영향을 미치는 게 문제가 되죠" (p256).
- 3부 '챗GPT로 데이터 분석 쉽게 하기'에서 이상치·통계량을 AI와 함께 처리하는 흐름 (p256).
- 마무리 프레이밍: "시장 조사, 고객 분석, 매출 예측, 보고서를 한 번에 — 코드 한 줄, 수식 계산 없이" (p513).
