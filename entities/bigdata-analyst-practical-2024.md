# 빅데이터분석기사 실기 기본서 Python 분석 (2024)

> "개념부→기출까지 제고하는 완벽 입문서 — 실전 학습: 각 분권 전문가가 집필한 쉽고 알찬 포인트 설명, 기출 복원 문제" (p1)

## 개요
- **저자:** 나홍석 외 공저 (고려대학교 AI빅데이터연구소) — p1 표지만 아티팩트 혼재로 일부 성명은 원본 PDF 대조 필요
- **출판:** Youngjin(license.youngjin.com) 2024년 수험서, ISBN 978-89-34-6768-0 (p1, p10)
- **쪽수:** PDF 304쪽
- **성격:** 빅데이터분석기사 실기 작업형 시험 대비 기본서. 파이썬 기반 데이터 전처리·분석 실습 + 기출 복원 문제 풀이에 초점 (p1, p12)

## 내용
- PART 구성: PART01 파이썬 프로그래밍(기초, 넘파이/판다스로 데이터 다루기), PART02 데이터 전처리(탐색적 데이터 분석, 전처리 개요, PCA 차원축소, 결측치·이상치 처리, 평활화), PART03 데이터 분석(빅데이터 분석 과정, 지도학습 Ⅰ분류, 지도학습 Ⅱ회귀) (p12).
- 타이타닉 데이터셋 실습: "데이터셋에서 탑승자들의 여러 속성 데이터를 기반으로 생존여부(Survived)를 예측한다" — 891행 × 12열, 이진분류 문제 (p152).
- 랜덤 포레스트 활용: "불필요한 속성을 제거하고 전처리과정을 거친 후, 사이킷런의 랜덤 포레스트 알고리즘을 이용하며 학습 모델을 구축한 후 예측을 수행한다" — n_estimators, max_depth 매개변수 조절 (p152).
- 필요 패키지: numpy, pandas, sklearn, RandomForestClassifier, train_test_split (p152).
- 모의고사 2회(모의고사 1회 226쪽, 2회 236쪽 영역) + 합격강의 수록 (p12).
- 부가 서비스: 스터디 카페(커뮤니티), 모의고사 무료 서비스, 기출 복원 문제 기반 모의고사 (p304).
