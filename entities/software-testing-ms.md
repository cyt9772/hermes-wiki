# MS 최고의 현직 테스터들이 밝히는 소프트웨어 테스팅

**앨런 페이지 · 켄 존스톤 · 비제이 롤리슨** 지음, **권원일 · 이공선 · 김민영 · 김윤명 · 여용구** 옮김(대표 역자 권원일, STA 컨설팅). 한국어판 2009년 10월 역자 서문. 571쪽. 마이크로소프트 현직 테스터들이 실제로 운영 중인 테스팅 프로세스와 베스트 프랙티스를 프로젝트 에피소드 형식으로 서술한 실전서.

## 장 구성 (원문에 기초)
- 01장 마이크로소프트의 소프트웨어 엔지니어링
- 02장 MS의 소프트웨어 테스트 엔지니어(역할·조직)
- 03장 엔지니어링 라이프사이클(개발 모델)
- 04장 테스트 케이스 작성을 위한 실용적 접근
- 05장 기능 테스팅 기법
- 06장 구조적 테스팅 기법
- 07장 코드 복잡도에 따른 리스크 분석
- 08장 모델 기반 테스팅
- 09장 버그와 테스트 케이스 관리
- 10장 테스트 자동화
- 11장 비기능 테스팅(~13장)
- 13장 고객 피드백 시스템
- 14장 소프트웨어 플러스 서비스 테스팅
- 15장 문제의 조기 해결
- 16장 테스팅의 미래

## 핵심 3~5개
1. **베스트 프랙티스라는 프레임**: "만병통치약은 없다, 기본 이론 + 경험으로 검증된 모범 사례만 있다" — 역자 서문의 책 전체 포지셔닝 `[raw/books/software-testing-ms.md]`
2. **테스트 엔지니어의 조직적 지위**: 02장에서 MS 안에서 테스터의 역할·권한·커리어를 별도로 정의 — 테스팅을 전업으로 하는 조직 문화의 토대.
3. **코드 복잡도 기반 리스크 분석**: 07장에서 복잡도 메트릭을 테스트 대상 우선순위 결정에 사용 — "어디에 노력을 쓸 것인가"를 정량화.
4. **버그·케이스 관리와 자동화**: 09장 버그 트리아지 프로세스, 10장 자동화 도입→전사 확산의 실제(도구 개발→도입→효과 측정→확산).
5. **고객 피드백 시스템**: 13장에서 Beta/고객 채널을 테스팅 루프로 편입 — 테스팅을 릴리스 이후 운영 정보로 확장.
6. **역자 서문의 한국적 의제**: 테스팅 인식이 열악한 한국 현장에서 "독하게" 국제·업계 표준(ISO/IEC 29119 등)을 공부·활용하면 단기간에 세계적 수준에 도달할 수 있다는 주장 — 이 책이 한국 테스팅 실무계에 미친 영향의 설명.
