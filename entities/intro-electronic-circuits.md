# 전자회로입문 / Electronic Circuits for Practitioners (Kim Byeong-gyu)

> 저자: **김병규** (Kim Byeong-gyu)
> 263p
> **주의**: 이 김병규는 [[kimbyeonggyu]] (올라마·LLM 에이전트 개발 입문 공저)와 **동일 인물 아님** — 전자회로 고장 진단 실무 서적 저자

## 개요
**전자회로 고장 진단·수리 실무** — "각종 전자회로 고장 진단 수리 해설". **기본 고장 진단(제1장)** → **1단 TR 증폭 회로(제2장)** → **직류 전원(제3장: 선형 안정화, 스위칭, 보호)** → **증폭 회로(제4장: class, 부귀환)** → **발진기·시간축(제5장)** → **펄스·파형 정형(제6장: 클리핑/클램프/인티그레이터)** → **사이리스터·트라이악(제7장)** → **아날로그·디지털 IC(제8장)** `[raw/books/intro-electronic-circuits.md]`.

## 장 구조 (TOC 기반, 263p)
1. **기본 고장 진단** — 소자 고장, 능동소자, 측정장비/방법, 고장 검출
2. **1단 TR 증폭 회로** — 저항/캐패시터/트랜지스터 고장, 실습
3. **직류 전원** — 선형 안정화, 스위칭, 보호 회로, 고장 진단
4. **증폭 회로** — 증폭기 종류(class), 부귀환, 테스트
5. **발진기·시간축 발생** — 주파수 측정/안정/고조파
6. **펄스·파형 정형** — 클리핑/클램프/인티그레이터
7. **사이리스터·트라이악** — 동작 원리, 응용
8. **아날로그·디지털 IC** — IC 입문, analog/digital IC
