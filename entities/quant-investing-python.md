# 손에 잡히는 퀀트투자 with Python

> 파이썬을 활용한 금융 데이터 분석과 퀀트 투자 전략 검증 (p2)

## 개요
- **저자:** GIL's LAB (박찬규 외) (p4, p5)
- **출판:** 위키북스 (WIKIBOOKS), 2022-02-22, 540p, ISBN 979-11-5839-313-7, Copyright © 2022 GIL's LAB (p3)
- **성격:** 파이썬·데이터분석 초보자가 퀀트 전략을 검증·수립하도록 GIL's LAB 블로그(https://gils-lab.tistory.com) 내용을 체계화한 실습서 (p5).

## 내용
- 집필 동기는 동학개미 열풍 속 "잘 알려진 투자 전략이 정말로 유효한지" 확인하고 싶은 호기심 (p5).
- 3부 구성: 1부 '파이썬 핵심 정리'(문법), 2부 '금융 데이터 수집'(주가·환율·종목 리포트), 3부 '퀀트 전략 구현 및 검증' (p5).
- 예제 코드는 깃허브 저장소 https://github.com/wikibook/quant 에서 관리·다운로드 (p6).
- 책 홈페이지 https://wikibook.co.kr/quant — 문의·오탈자 안내 (p6).
