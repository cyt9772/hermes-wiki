# POINT CHECK — 초보부터 고수까지 파이널 노트 (육미희)

> '강남에서 수많은 학생들에게 영어를 가르치면서 한국인이 자주 저지르는 실수 패턴이 존재한다는 것을 알게 되었다' (p2 저자 소개)
## 개요
- **Author:** 육미희
- **Publisher:** OCR상 불분명  |  **Pages:** 242
- **Positioning:** 초보→고수 '파이널 노트' — 한국인이 자주 저지르는 영어 실수 패턴(Point)별 집중 정리.
## 구성
- 실수 포인트(Point) 진단 → 확실하게 넘어가는 학습 설계 (p2).
- 부정사·구문 실전 포인트 (p30).
