# Teach Yourself C++ (정보문화사 번역판)

> 표지: '단계별 예제와 연습을 통해 객체 지향 프로그래밍을 탐구합니다 … C/C++ 3.1 포함' (p1)

## 개요
- **저자/역자:** Jesse Liberty 저, 양재찬 역 (p2)
- **출판:** SAMS Publishing(원서) / 정보문화사(번역), Complete Compiler Edition — ISBN 0-672-31261-1, 번역판 ISBN 89-7627-465-2 (p3, p858)
- **성격:** 21일 자습식 C/C++·객체지향 입문서, PDF 858쪽. '이 책을 21일간 자습할 수 있도록' 구성, 각 개념을 리스트 코드(예제)로 실력을 배양 (p858).

## 내용
- 번역 서문: '전산학적 깊은 토대 위에서 일반 C 언어를 설명하였고 … 초보자로 잡았음에도 중급자들에게도 상당히 유익하도록' (p4).
- 객체지향 핵심 학습 — 'C++ 특징을 완전히 소화하기 위해 … 모든 ANSI 표준 [C++ 언어]로 동작할 수 있습니다' (p858).
- 21일 구성의 13일 차 다형성(polymorphism) — Horse·Bird 기반 Pegasus 클래스 예제와 생성자 호출 순서 (p429).
- 모호성 해결(Ambiguity Resolution) — Horse와 Bird가 같은 메소드를 공유할 때 Pegasus에서 발생하는 문제 (p429).
- 저자 Jesse Liberty가 객체지향 분석·설계에 관해 6권의 책을 썼고 AT&T·Xerox·PBS에서 소프트웨어 엔지니어 경험 (p858).
