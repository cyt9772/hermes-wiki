# 비디오 압축 표준 (MPEG을 중심으로) (김진태 1999)

> 표기/원저: **김진태** (경성대학교)
> 출판: 나남출판 — 경성대학교 〈멀티미디어 연구총서〉 19권, 1999, 118p

## 개요
경성대학교(1997년 국내 유일 멀티미디어 특성화대학 지정)가 발간한 〈멀티미디어 연구총서〉의 영상 압축 표준 편. MPEG 표준화 활동의 역사와 프로세스(제1장) → **MPEG-1** 영상압축 기술(제2장) → **MPEG-2** 영상압축 기술(제3장) → **MPEG-4** 표준화 방향(제4장) → **새로운 방향의 MPEG**(MPEG-7 등, 제5장)으로, 표준화 프로세스와 각 세대 표준의 영상압축 기술을 일반 독자가 접근할 수 있는 수준에서 정리한다. MPEG의 오디오·시스템 파트를 배제하고 **비디오 파트만** 다룬다 `[raw/books/video-compression-standards-korea.md]`.

## 장 구조 (TOC 기반, 118p)
1. **MPEG의 표준화 활동** — ISO/IEC JTC1/SC29/WG11, 표준화 역사, 프로세스
2. **MPEG-1의 영상압축 기술** — 저장매체용, I/P/B 픽쳐, GOP
3. **MPEG-2의 영상압축 기술** — 고화질 확장, Profiles/Levels, 계위 부호화
4. **MPEG-4의 표준화 방향** — 컨텐츠 기반 부호화, VOP
5. **새로운 방향의 MPEG** — MPEG-7 등

## 핵심 내용
- **표준화 프로세스**: MPEG(ISO/IEC JTC1/SC29/WG11)의 표준화 활동을 제1장에서 체계적으로 정리 `[raw/books/video-compression-standards-korea.md]`
- **MPEG-1 영상압축**: 저장매체 기준, I/P/B 픽쳐 구조, GOP 구성 `[raw/books/video-compression-standards-korea.md]`
- **MPEG-2 영상압축**: 고화질(HD급) 표준, Profiles/Levels, 계위(temporal/spatial/SNR) 부호화 `[raw/books/video-compression-standards-korea.md]`
- **MPEG-4 방향**: 컨텐츠 기반(video object plane) 부호화, VOP 개념 `[raw/books/video-compression-standards-korea.md]`
- **표준화 흐름**: H.261 → MPEG-1 → MPEG-2 → MPEG-4 → MPEG-7의 세대별 진화를 단일 서사 안에서 정리
