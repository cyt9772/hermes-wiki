# C++ Primer (3rd Edition)

> 뒷표지: 'The third edition of the C++ Primer combines Stanley Lippman's practical experience with Josee Lajoie's inside knowledge of the ANSI/ISO Standard C++' (p1257)

## 개요
- **저자:** Stanley B. Lippman, Josee Lajoie (p2, p3)
- **출판:** Addison-Wesley (원서), 1998 © AT&T, Objectwrite, Inc. (p3)
- **성격:** ANSI/ISO 표준 C++을 다루는 종합 입·중급 프로그래밍 교재, PDF 1257쪽. 객체지향 설계, 템플릿, STL·제네릭 알고리즘 등 실전 C++ 사용법과 효율성 지침을 다룸 (p1257).

## 내용
- 표준 C++에 초점을 맞춘 종합 튜토리얼 — ' Especially useful for developers new to C++ are the many real-world programming examples that illustrate the design of generic and object-oriented programs, the use of templates' (p1257).
- STL 컨테이너의 멤버 기능 상세 해설: `list::remove()`, `list::remove_if(Predicate)`, `list::reverse()`, `list::sort(Compare)` — sort 기본은 작은-연산자 기준 오름차순, `sort(greater<int>())`로 내림차순 (p627).
- 가상 함수와 가상 상속(virtual inheritance) 체계 — 가상 함수의 기본 인자·생성/소멸자 호출, 순수 가상, 다중 상속에서의 가시성 (p1255 색인).
- 함수 오버로딩 리졸루션, 참조, const/volatile·정적 변수 등 핵심 언어 메커니즘 색인으로 확인 (p1255).
