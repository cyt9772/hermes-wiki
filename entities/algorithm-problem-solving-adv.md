# 알고리즘 문제해결 중급과정 해설

> 첫 번째 비트가 1인 경우 음수이므로 '-' 를 출력한 후 2의 보수로 변환하여 10진수로 출력하면 된다. (p20)

## 개요
- **출판:** 한컴에듀케이션 | 292쪽 | pdftotext 직접 추출 (정올 사이트 문제번호와 연동)
- **포지셔닝:** BOJ(백준) 중급 문제를 정올(www.jeongol.co.kr) 문제번호 기준으로 해설한 문제풀이서. 정렬·스택/큐·그리디·그래프/BFS·동적계획·구간트리 등 실전 코딩테스트 위주.

## 내용
- 진법 변환: 2진수를 10진수로 (1274) — '10101 = 1*2^4 + 0*2^3 + … '로 재귀·Horner적 전개, '256 - 152 = 104' 음수 처리 (p20). 10진수를 2/8/16진수로 (1534) — 16진수 A-F 표현 (p21).
- 정렬과 스택/큐: 4 3 (SORT, 1972), 힙 정렬 (Heap_Sort, 2082), 책꽂이 만들기 (1929), 스택(1102), 큐(1697), 마법색종이(1264), 요세푸스 문제(3101) (p2-3).
- 그리디와 그래프: 회의실 배정 (1370), 공주님의 정원 (2461), 해밀턴 순환회로 (1681), 루빅의 사각형 (2250), 미로탈출 게임 (3010), 장기 (1106), 로봇 (1006) (p3).
- 동적계획과 구간: 두 줄로 타일 깔기 (1411), 계단 오르기 (1520), 짚신벌레 (1822), 배낭 채우기 (1077/1278), 줄 세우기 (1871/2469), 구간의 최대값 구하기 (1726), 공장 (2615) (p3-4).
