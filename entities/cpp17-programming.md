# 시작하자! C++17 프로그래밍 (개정판)

> 표 1: '현란한 구글 코딩 스타일과 정교한 [개발] 표준에 입각한 C++ 언어 학습서' (p1)

## 개요
- **저자:** 박헌재 (25년간 유닉스·리눅스·자바 분야 개발 수행. 주요 저서 '안드로이드 C/C++ 프로그래밍', '기적을 부르는 안드로이드 통신 프로그래밍') (p3)
- **출판:** 투에이치앤에스 (p2, p3)
- **성격:** C 언어 기본 문법을 아는 독자를 전제로 한 C++17(개정판) 학습서, PDF 795쪽. 2020년 07월 초판 1쇄 (p3).

## 내용
- C++ 명명 원리 — 'C는 C 언어를 뜻한다. ++ 는 단항 증가 연산자인 ++ 를 의미한다. 따라서 C++ 언어는 C 언어에 비해 더 많은 기능을 추가해 증가시켰다' (p4).
- 독자는 '최소 C 언어가 제공하는 기본 문법에 대해 어느 정도 알고 있다는 가정 하에서 출발' (p4).
- 의존 타입(Dependent type)과 `enable_if` 구조체 템플릿을 이용한 `min()` 오버로딩 — 템플릿 인수가 lvalue 참조 여부에 따라 활성화/비활성화, 의존 타입은 `typename` 지정자로 명시 (p397).
- '템플릿은 프로그램이 아니고 컴파일 시점에 확정되는 메타 프로그램이기 때문에' 같은 템플릿 매개변수 두 함수도 문제가 안 되며, 두 구조체가 동시에 활성화되면 에러 (p397).
- 스마트 포인터, 스레드 컨트롤 블록, 유니버셜 참조, 임계구역, 제네릭 등 C++17 핵심 주제를 색인으로 확인 (p792).
