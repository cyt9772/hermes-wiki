# 제미나이 노트북LM

> 표지: '제미나이 최신 모델 / 최강 리서치 노트북 / 원클릭 팟캐스트 생성 — 오힘찬 지음' (p1, p2)

## 개요
- **저자:** 오힘찬 지음 (p2)
- **성격:** 구글 AI 서비스(Gemini + NotebookLM) 실무 활용서. '일잘러 오대리의 AI 활용법'을 표어로 내세우며, 회의·조직 관리·협업 등 실무 관점의 AI 활용법을 다룬다 (p1). PDF 310쪽.

## 내용
- 구글 I/O 2025 비전 소개: '제미나이를 보다 개인화되고 능동적인 정보 에이전트로 발전시키려는 비전을 보여주었다' — 실시간 시각 검색, 에이전트 기능 통합, 데이터 분석·시각화, AI 쇼핑, 스마트 안경(확장현실) 탑재까지 다룬다 (p3).
- 모델 선택 가이드: Chapter 01 'Ok, 제미나이'에서 모델 명칭, 입력 유형, 출력 유형, 토큰 한도, 핵심 기능 특징을 비교하는 실무 방법을 제시 (p27).
- 활용 범위: '일잘러 오대리의 AI 활용법' 표제대로 문서·회의·협업까지 실무 AI 워크플로와 LLM 활용법을 다룬다 (p1).
- NotebookLM(리서치 노트북)의 원클릭 팟캐스트 생성 등 콘텐츠 생성 기능을 중심으로 실무 활용법을 실습 (p1).
