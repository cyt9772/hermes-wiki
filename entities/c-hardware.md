# C로 하드웨어 건드리기

> 추천사: "모든 프로그래밍 언어는 나름대로 독특한 탄생 배경을 가지고 있으며 그 배경에 기인한 특성들을 가지게 됩니다" (p4)

## 개요
- **Author:** 김석주 저
- **Publisher:** PC 어드반스 (PC Advance)
- **Pages:** 584
- **Positioning:** "소스코드로 배우는 C로 하드웨어 건드리기" (p2). DOS/PC 환경에서 키보드·마우스·비디오(텍스트/그래픽)·메모리·타이머·스피커를 C로 직접 제어하는 시스템 프로그래밍 실무서 (1994년 3월 머리말).

## 내용
- C와 하드웨어: "인기를 얻고 있는 것은 하드웨어 시스템을 직접 제어할 수 있는 여러 가지 기능을 제공하고 있기 때문입니다" (p4).
- 독법: 하위 하드웨어를 잘 모르거나 시스템 프로그래밍 경험이 없는 사람은 "반드시 읽어야 하는 부분이다" (p18).
- 구성: 키보드를 화면에 출력하는 과정, 마우스 디바이스 드라이버/이벤트 핸들러, 텍스트 모드·비디오 메모리 직접 접근, 허클리스/VGA 그래픽 모드, 타이머·스피커 함수를 만들어 보게 한다 (p18–20).
