# 나의 첫 알고리즘 + 자료구조 (with 파이썬)

> 유한함 (Finiteness) 이란 알고리즘이 유한한 단계를 거친 후 종료된다는 뜻입니다. (p20)

## 개요
- **저자/출판:** 코리 알트호프(Cory Althoff) 지음, 한선용 옮김, 한빛미디어 | 2023 | 294쪽 (The Beginner's Guide to Data Structures & Algorithms, 2022)
- **포지셔닝:** 비전공자·입문자를 위한 파이썬 기반 알고리즘+자료구조 입문서. 저자 본인이 정치학 전공 → 파이썬으로 전환한 학습 여정을 배경으로 '어려움 없이' 접근하는 방향.

## 내용
- 알고리즘 요건: 명확함(Definiteness), 효율성(Effectiveness), 유한함(Finiteness), 정확성(Correctness) — '알고리즘은 입력이 같으면 항상 같은 결과를 내야 하며, 이 결과가 알고리즘이 해결하는 문제의 정확한 답이어야 한다' (p20).
- 실행 시간 측정: time.time() 모듈을 활용한 1~5 출력 예제와 소요 시간(0.15초) 측정 — 측정 실행을 통해 '알고리즘의 실행 시간' 개념을 체험 (p21).
- 정렬: 리스트 정렬의 다양한 방식(삽입·합병·퀵 등) 비교. '가장 단순한 것? 가장 빠른 것? 가장 짧은 것?' — 실행 시간 외 기준 제시 (p20-21).
- 근사 알고리즘 예: 난수 발생기(Random Number Generator)는 결과를 예측할 수 없다는 무작위성 목표, 추정 알고리즘은 정확성을 엄격히 따지지 않아도 충분 (p20).
