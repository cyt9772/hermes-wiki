# 팝스 영단어 (Pops Vocabulary)

> '팝송으로 쉽게 끝내는 팝스 영단어 — 원음과 생생한 단어' (표지·목차)
## 개요
- **Author:** 김태형 (영어전문 프로듀서·팝칼럼니스트; '2008 English', 'How Do You Do?' 연출, Mr. Pops)
- **Publisher:** 인터윈 (2006-04-15)  |  **Pages:** 342
- **Positioning:** 팝송 가사 중심 어휘 학습 — daum 'Pops Voca' 카페 연동, '원음과 생생한 단어'.
## 구성
- 곡 단위 학습: Hotel California, (It's Because I Love) You Missing... — 'Check Test / 번역' 반복 구조 (p8 목차).
- 다 외운 뒤 '여자/남자친구에게 전화 걸어 팝송 표현으로 폼 잡기' — 실전 회화 연결 (p5).
- 어휘 예: resentment [rizéntmont] '분개, 원한 — feel resentment' / awe / fright / horror (p40).
