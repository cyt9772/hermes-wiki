# 주식대학 실전투자전략 (2)

> 표지 (p1): '"산업을 이해하고 기업을 (이)해해야 돈의 흐름이 보인다!"' — '국내 최고 (애)널리스트 21명이 방송에서 하지 못했던 업종 분석 수록. 이경수, 김현, 이진우, 박형렬, 윤여삼, 김선우, 김준성 등'

## 개요
- **저자:** 이경수 외 (메리츠증권 애널리스트 21명)
- **출판:** 메리츠증권 '주식대학' 시리즈 2권
- **성격:** 업종 분석 중심의 실전 투자전략서, PDF 632쪽. 6강~10강(음식료·반도체/디스플레이·정유/화학·건설/부동산·제약/바이오).

## 내용
- 구성 (Contents, p2): 6강 음식료 (p5) → 7강 반도체/디스플레이 (p167) → 8강 정유/화학 (p323) → 9강 건설/부동산 (p429) → 10강 제약/바이오 (p551).
- 1권(투자 기초·실무 원칙)의 이어서, 개별 업종 밸류체인 분석에 집중:
  - 음식료: '음식료 산업과 곡물 가격 전망' (Part I, p3)
  - 반도체/디스플레이, 정유/화학은 사이클 산업의 가격·능력 확충 분석 프레임
  - 건설/부동산, 제약/바이오는 정책·규제 민감 업종 분석
- 각 업종에 대해 해당 분야 전문 애널리스트가 방송보다 더 깊이 있는 업종 분석을 수록 (표지 강조 포인트).
