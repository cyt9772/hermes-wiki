## 7가지 기술 (개별 페이지 참조)
1. **인공지능** — 데이터(무가치) → 가치 전환하는 도구 [[artificial-intelligence]]
2. **5G** — 초연결 기반 (세븐 테크의 통신 지층)
3. **블록체인** — 공정·투명·불변·가용, 디지털 경제 인프라 [[blockchain]]
4. **AR/VR** — 메타버스의 감각·공간 계층 [[metaverse]]
5. **로봇** — 7개 기술 중 유일하게 물리적 세계에 직접 작용 [[robotics]]
6. **사물인터넷** — 만물 연결, 데이터 원천 [[iot]]
7. **클라우드** — 공유 기반 인프라, "기회의 신은 클라우드 안에 있다" [[cloud-computing]]

## 투자 관점에서의 활용 (위키 도메인 연결)
- 2022년 기준 **'7가지 기술'은 곧 테마섹터 지도**: 반도체/5G 장비, 클라우드 인프라, 로봇·자율주행, Web3(NFT·게임).
- NFT 실사례 (p199–200): 공연 영상 컷의 NFT 경매 판매 — **디지털 콘텐츠 자산화 (Web2 엔터 → Web3)** 초기 사례. 게임(포트나이트), 엔터(아리아나 그란데) 산업 연결.
- 로봇 (p40): [[robotics|배어로보틱스]] 사례 — 서빙로봇 스타트업, 2017년 창업, 2020년 SoftBank 대규모 투자 유치. (K-로봇 상장주 테마의 전철적 근거)
- IoT (p155): Apple(watch), Tesla(자율주행), Amazon(에코) — **대형사의 IoT 사업 전략이 이미 진행 중** 이라는 관찰.
- 클라우드 (p168): "소유 → 공유" 비즈니스 모델 전환의 근거.
