# 시대의 1등주를 찾아라

**페이지2룩스 (2021-09-08 초판) — 이한영 지음.** "펀드매너저처럼 생각하고 투[자]하는 법" (OCR). 3부 + 나가는 글로 나뉘어, 톱다운으로 '시대의 1등주'를 찾는 개인투자자 가이드.

## 한 줄 요약

> **주식 투자의 본질은 '개화기→성장기 사이클'의 폭발적 성격을 '단 한 종목(1등주)'에 집중해서 먹는 것.**

2년간 '베스트 펀드매니저'를 석권한 저자 (p001)가 17년간 반복해온 '주식 공부 루틴'을 공개: ①주가의 함수·변곡점 분석 → ②산업·섹터 사이클 검증 → ③밸류체인 → ④1등주 선별 → ⑤PER·PBR 목표가 → ⑥기업 분석 리포트 작성.

## 투자 관점

- **1등주 집중 투자** (p105-106) — "1등주를 가진 투자자는 마음이 편하다. 단지 이것보다 더 [좋은] 주식이 있는지만 판단하면 되는데, 2등주를 가진 투자자는 1등주를 부러워하면서 자신이 가진 주식을 다시 한번 판단해야 한다" (p105). "시대의 1등주에 투자하라! … 대장주가 답이다" (p106 SUMMARY).
- **개화기→성장기 3~10년 집중** (p098) — "산업은 개화기, 성장기, 성숙기, 쇠퇴기를 거치는데 주식은 개화기와 성장기 사이의 폭발적인 성장률을 먹는 게임이다" (p098) → [[momentum-investing]]·[[top-picking]].
- **0→무한대 신산업 우선** (p116) — '2차전지', '제약·바이오' (p116). "0.1% → 1%는 10배 성장" (p116).
- **1등주·2등주 시총·수익률 격차 판독** (p103-105) — 삼성전자 4%→22% (1994→2019) vs LG전자 1.7%→0.9% (p105) → [[relative-strength]].
- **실적 분기별 로테이션** (p144, p156) — "실적 시즌(1, 4, 7, 11월) … 그 이후로는 추세가 형성된다" (p144) → [[sector-rotation]].
- **톱다운 접근** (p010, p065) — "시장 환경을 알아보고 여기서 내가 가져야 할 마음가짐을 알아보는 것" (p010).
- **밸류체인 = 답지** (p138) — "밸류체인의 정리는 산업 공부의 답지가 된다" (p138).
- **데이터로 검증** (p131-132) — "데이터는 거짓말하지 않는다" (p132), 수출/산업부 통계로 섹터 사이클 확인.
