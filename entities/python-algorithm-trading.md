# 파이썬으로 배우는 알고리즘 트레이딩

> 내 손으로 만드는 자동주식 거래 시스템 — "프로그래밍 책이지만 비전공자와 일반인이 파이썬을 쉽고 재미있게 배울 수 있어야 한다"는 목표로 집필 (p5)

## 개요
- **저자:** 조대표 (조현호) (p5, p6)
- **출판:** 위키북스, 1쇄 2019-03-07 / 3쇄 2020-09-10, 724p, ISBN 979-11-5839-484-6 (p3)
- **성격:** 국내 알고리즘 트레이딩 입문서. C/C++ 기반이던 국내 알고리즘 트레이딩 문턱을 파이썬으로 낮추고, 주식 노하우를 프로그램으로 구현하는 법을 다룸 (p5).

## 내용
- 집필 동기는 국내에 초보자가 참고할 입문서가 없어: "국내에 알고리즘 트레이딩 분야에서 초보자들이 참고할 만한 입문서가 없기 때문" (p5).
- 백테스팅 개념 정립 — "개발된 알고리즘을 과거 데이터를 사용해 검증해보는 것을 의미" (p381).
- pandas_datareader로 애플 종목 과거 데이터 수집, Zipline(Quantopian의 알고리즘 트레이딩 라이브러리)으로 백테스팅 기초 실습 (p383, p390).
- 14장 "pandas와 Zipline을 이용한 백테스팅"에서 이동평균선 전략 백테스트까지 이어지는 구성 (목차 p15, 본문 p380~390).
