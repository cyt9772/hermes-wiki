# C 프로그램 이렇게 짠다

> 머리말: '... ANSI 표준에 맞추고, 개발은 Turbo C와 MS-C[로] 수행했다' (p4)

## 개요
- **저자/편저:** 편저자는 서울대 출신 (1962 서울대, 1976~1987 서울대 교재) — 저서로 'C 프로그램 이렇게 짠다', 'TURBO C 2.0 활용 안내와 기초', 'CROSSTALK 16 및 데이터 통신 기초와 RS-232C' (p1097). 원저서 기반: Herbert Schildt 'C: Power User's Guide' (p2, p4)
- **출판:** 1991년 9월 25일 초판, 1993년 7판 인쇄, ISBN 89-09-00132-1, 정가 15,000원 (p1097). 발문은 교학사 'C 언어 기초'의 다음 단계로 고급 프로그라운머를 향해 (p2)
- **성격:** 고급 C 프로그래밍 교재, PDF 1097쪽. 원저서 10장 + 본저자 추가 8장 = 총 18장 (p2).

## 내용
- 10년을 넘게 C 경험을 쌓은 노련한 프로그래머가 쓴 'C: Power User's Guide'를 기반으로 보완·편집 (p2).
- '성공적인 작품이란 특정 응용에 대한 정확한 파악을 했을 뿐 아니라, 운영체제와 하드웨어 자체를 포함해서 전반적인 컴퓨터 환경의 완전한 통솔(complete mastery) 지식을 가진 사람에 의해서 설계' (p2).
- 주요 항목: '비디오 RAM 직접적 액세스 기술', '메모리 상주 프로그램 작성법', '마우스 인터페이싱', '물체 회전을 포함한 그래픽 기능', '언어 인터프리터(Interpreter) 작성법' (p3).
- '초보자로부터 전문가에 이르기까지' 대상 — 초보자는 예제 프로그램을 작동 세부사항을 모르고라도 활용, 고급자는 루틴을 응용의 기본으로 사용 (p3).
- '모든 소스 프로그램과 컴파일이 끝난 실행 가능 프로그램은 첨부된 디스켓에 제공' (p4). ANSI 표준 준수 — '모든 프로그램 루틴들은 ANSI [C] 를 지원하는 어떤 컴파일러 상에서도 컴파일될 것이다' (p4).
