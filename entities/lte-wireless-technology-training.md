# 무선통신기술의 이해 (현대차 LTE 특강 2014)

> 표지/원저: 현대자동차 (Hyundai) — LTE 프로세스 기술 교육 자료
> 강사: 윤석현(한국대학교수), 김재현(아주대학교 교수) 등
> 출판: 현대자동차 내부 교육 자료 (외부 출판사 표기 없음), 2014, 387p

## 개요
"Hyundai Next Generation Vehicle Technology" 프로그램의 LTE 특강 슬라이드. 4일 과정으로 LTE 시스템 기반 무선 기술(OFDM/SC-FDMA, MIMO) + Radio Interface(PHY/MAC/RRC) + 네트워크 기술(핸드오버/RRC/RRM) + LTE-A features(Rel.10/11)를 다루며 `[raw/books/lte-wireless-technology-training.md]`, 2014. 1. 8-9(일) 실습 포함. 조직(현대차) 저자 + 강사 실명(윤석현·김재현) 혼재 — 개인 저자 페이지 생성 불가, 회사/강사 명의로 표기.

## 장 구조 (process schedule + TOC)
- **1일차** — 오리엔테이션, LTE 시스템 기본 무선 기술 (OFDM 및 SC-FDMA, MIMO/Beam-forming·Spatial Diversity·Multiplexing)
- **2일차** — LTE Radio Interface / Architecture (PHY center) — LTE Physical Layer, downlink·uplink 전송 규격, 다중 접속 기술
- **3일차** — LTE Network Architecture — user/control plane, LTE RLC/RRM, 채널 적응 스케줄링·링크 적응
- **4일차** — LTE 프로토콜 / LTE-A features (Rel.10/11) — CoMP, heterogeneous network (HeNB), D2D, MTC

## 핵심 내용
- OFDM(sc-FFT)·SC-FDMA(uplink)·MIMO(빔포밍·space-time diversity·multiplexing) 등 LTE 물리 계층 핵심 기술 `[raw/books/lte-wireless-technology-training.md]`
- LTE Radio Interface — PHY/MAC/RRC 계층별 동작과 프로토콜 매핑 `[raw/books/lte-wireless-technology-training.md]`
- LTE Network Architecture — E-UTRAN + EPC, user/control plane, 핸드오버·세션 관리 `[raw/books/lte-wireless-technology-training.md]`
- LTE-Advanced (Rel.10/11) — CoMP, heterogeneous network, carrier aggregation, beam steering `[raw/books/lte-wireless-technology-training.md]`
- 3GPP LTE 표준화 과정과 WCDMA/HSPA 진화 경로 — 표준/기술 배경 `[raw/books/lte-wireless-technology-training.md]`
