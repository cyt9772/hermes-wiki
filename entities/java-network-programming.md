# Java Network Programming

> 당시 자바 네트워킹 기술에 소프트웨어 공학적 접근을 시도한 최고의 서적이라는 극찬을 받으며 매닝(Manning) 출판사의 간판 타이틀로 떠올랐던 이 책 (p4)
## 개요
- **저자(원서):** Merlin Hughes, Michael Shoffner, Derek Hamner, Umesh Bellur
- **편역:** 고려대학교 컴퓨터학과 시스템연구회 (S76)
- **쪽수:** 1139p (OCR 추출, 로컬 PDF `/run/media/yutae/Data/Java Network Programming.pdf`)
- **위치화:** 자바 기반 네트워킹·스트림·쓰레딩·분산컴퓨팅·암호화의 바이블. '자바로 할 수 있는 네트워킹 뿐만 아니라 거의 대부분의 프로그래밍에서 쓰는 스트림 조작, 쓰레딩, 예외 처리 기법'을 다룸 (p5).
## 내용
- 용어 대역: '네트워킹 관련 용어의 대역어 선정에 있어서는 자연스러움을 원칙으로 하였다' — 업계에 익숙한 '로컬'을 '지역' 대신 사용, RMI 등 분산객체 개념에서는 '원격'을 쓰도록 (p35).
- 클래스 지문 번역: 'DNSInputStream. 이 클래스는 DNS 응답시 반환되는 일반적인 데이터를 디코딩하는데 쓰이는 보조 메소드를 가진 InputStream 클래스(InputStream 확장한 서브클래스라는 뜻)이다' (p35).
- 원고 참고 리소스: Internetworking with TCP/IP (Comer), Computer Networks — A Systems Approach (Peterson & Davie) 등 (p35).
