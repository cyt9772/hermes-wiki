# 사물인터넷을 품은 라즈베리파이 (7쇄)

> 저자: 김성우
> 국내서 | 제이펍, 초판 2016 / 7쇄 2019
> 615p `raw/books/raspberry-pi-iot-im.md`

## 개요
라즈베리파이 + 리눅스 + Python으로 **보 설치-리눅스 접속-파일시스템-기본/일반/시스템관리 명령-셸 프로그래밍-파이썬-웹 서버-데이터베이스-GUI**까지 실습하는 국내 입문서. "사물인터넷을 품는다"는 부제처럼 Python + Web + DB + GUI를 Pi 위에서 종합 `raw/books/raspberry-pi-iot-im.md`.

## 특징
- 리눅스 셸(2장) - 파이썬(3장) - 웹(4장) - DB(5장) - GUI(6-13장) 순의 "애플리케이션 개발" 관점
- GUI(위젯·시그널/슬롯·프레임)를 별도 다룸 — 다른 RPI 책보다 "앱 개발" 비중 큼
- 7쇄(2019)에 이르기까지 2000년대 중반 표준 RPI 입문서로 활용
