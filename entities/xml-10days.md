# 10일 만에 배우는 XML

Yamada Yoshihiro (山田善弘) 저, SHOEISHA Co., Ltd. (일본) 2001 "XML 入門教室" 원저. 한국어판: 영진닷컴 (Youngjin.Com) 2002, 이오커뮤니케이션 감수. **제0일 + 제1~10일 × Lesson 구조의 XML 실무 교과서.** XSLT + DOM + 스키마 + JSP까지.

## 인용
> "XML이 SGML의 문제 의식을 기초로 생겨난 언어라는 것은 분명하지만, XML은 단순한 웹상의 표현 언어에 머무르지 않고 보다 폭넓은 가능성을 가지고 있습니다."

## 구성 (제0일 + 제1~10일)
- **제0일 오리엔테이션** — XML이란 무엇
- **제1일** (L1-L2): XML 기본 / 다양한 작성법
- **제2~4일** (L3-L9): XSLT 레이아웃·상세 표시·고급 XSLT+α (xPath 함수, 유지 보수성, 상세 제어)
- **제5~6일** (L10-L15): DOM 프로그래밍①② — XML 문서 읽기 / 요소·属성 추출 / 노드 추가·갱신·삭제
- **제7일** (L16-L17): DTD + XML 스키마 (스키마 정의, 문법 체크)
- **제8~9일** (L18-L24): JSP + XML (서버·클라이언트 양방향, 동적 정렬, CSV 변환, 도서 검색 앱)
- **제10일** (L25): 실전 프로젝트 (도서 검색 시스템 + 테스트)
