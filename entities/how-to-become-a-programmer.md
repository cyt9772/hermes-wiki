# 아무도 알려주지 않는 프로프로그래머가 되는 길

**김상호** 저, 도서출판 아이콘(발행인 문서영), 1995년 3월 12일 초판. ISBN 89-8126-002-8. 711쪽. "초보와 프로는 종이 한 장 차이보다 작다"는 표어를 내세운, C 언어 기반의 실전 프로그래밍 성장서. 초보 프로그래머에서 중·고급으로 가는 경로의 기술적·정신적 단계를 4부 구성으로 담음.

## 부 구성 (원문에 기초)
- **1부 초급자를 넘어서기 위한 첫 걸음** — 1장 나의 위치 파악, 2장 프로그램이란(알고리즘, 개발과정) 등 C 진단.
- **2부 이런 것들은 알고 시작하자** — 하드웨어 구성, BIOS, DOS(IBM-PC) 기반 운영 원리. "반드시 소화해야 할 부분".
- **3부 프로를 흉내 내자 / 프로로 가자** — C 함수 직접 작성, VGA·그래픽·한글 처리, 락(복사 방지), 바이러스 구성 원리 구현, 데이터 압축(허프만 코딩, LZSS), 게임 프로그래밍 기초.
- **4부 이제는 나도 프로다** — 방향 점검, 현직 프로그래머들과의 대담 자료, 변하는 컴퓨팅 환경의 대응.
- **부록** — 참조 테이블·값 정리.

## 핵심 3~5개
1. **C를 매개로 한 실전 스펙트럼**: 함수 직접 작성 → VGA/그래픽 → 바이러스 구조 → 압축 알고리즘 → 게임, "직접 만들어 본다"가 각 장의 축 `[raw/books/how-to-become-a-programmer.md]`
2. **알고리즘의 실용성**: 2장에서 "좋은 알고리즘을 위한 선결조건" — 경험적 지식 vs 알고리즘을 구분. 프로그램 개발과정(2.4절)에서 알고리즘 설계의 위치를 다룸.
3. **프로의 마인드셋**: 초보↔프로의 차이를 기술 역량보다 사고방식(끝없는 호기심, 끈기, 대담)에서 규정 — 4부 현직 프로그래머 대담이 이 축을 실증. "초보와 프로는 종이 한 장 차이보다 작다"는 표어가 책 전체의 주제.
4. **1995년 C 실전서**: DOS/BIOS/VGA 중심이라 시대가 묻히지만, "프로가 어떻게 생각하는가"의 서술과 압축(허프만·LZSS)·그래픽·게임 구현 실습은 시대를 초월.
5. **참고 문헌에서 본 90년대의 C 프로그래밍 전역**: DMC(박명순)·게임(김종찬)·둠(김상호 역) 등 동시대 실무서와 함께 읽어야 90년대 중반 C 프로그래밍 현장이 보인다.
