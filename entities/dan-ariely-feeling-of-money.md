# 부의 감각

**댄 애리얼리 + 제프 크라이슬러, 청림출판 (2018).**
원서: *Dollars and Sense: How We Misthink Money and How to Spend Smarter* (2018).
행동경제학에서 가장 잘 알려진 실험 설계자 중 한 명인 애리얼리가, 일상에서 왜 돈을 "잘못" 쓰는지에 대한 17개 편향과 대안을 정리한 대중서.

## 한 줄 요약

> 우리는 모두 "돈의 환상"이라는 유리상자 안에 있다. (p11)
> 돈이 우리를 위해 해주는 일, 그리고 우리가 그 돈을 어떻게 잘못 쓰게 되는지를 17가지 편향으로 해체한다.

## 핵심 논증 흐름

1. **돈의 환상** (ch.1, p11): 우리는 "돈"이라는 추상 개념에 묶여 실제로 무엇을 얻는지, 무엇을 희생하는지를 계산하지 않는다.
2. **가격의 상대성** (ch.3-4, p50-53): "반값"은 과거 가격과 현재 가격의 비교일 뿐, 절대 가치를 평가하는 게 아니다.
3. **심리적 회계** (ch.5, p339-340): 같은 1달러라도 출처·장소·용도가 다르면 가치가 달라진다.
4. **지불의 고통** (ch.6, p121, p339-341): 현금 = 고통; 크레딧/공짜 = 고통 소멸 → 과소비.
5. **과신과 앵커** (ch.7, p341): 전문가도 무의식적 앵커에 끌린다; "나만의 판단"은 실은 앵커의 변형.
6. **소유 효과 / IKEA** (ch.8-9, p156, p342): 내 것 = 더 가치 있음; 직접 만든 것 = 더 가치 있음.
7. **현재편향** (ch.12, p253): 미래의 나는 "케이크"를 참을 것이라 믿지만, 지금의 나는 케이크를 고른다.
8. **자기-담고과 저축** (ch.16-17, p349): 의지력 대신 자동화.

## 투자 관점

- **지출 통제**: 크레딧 → 현금 전환 시 "지불의 고통"이 복원되어 과소비가 줄어듦 (ch.6, p121, p339).
- **심리적 회계 인식**: "투자용 계좌"와 "생활용 계좌"를 분리하고, 각각의 용도/기한을 명시하면 자산배분 판단이 개선 (ch.5, p339).
- **앵커 탈피**: 주가의 "원래 가격"이 결정적 앵커가 됨. Tversky-Kahneman 기준 (p341) — 절대 가치 평가로 재프레이밍.
- **현재편향 완화**: 자기-담보(자동이체, 투자 실행 일)를 의지력 대체 장치로 사용 (ch.16, p349).
- **소유 효과 경계**: 보유 종목 = 더 가치 있다고 느끼는 편향 (IKEA effect 변형, p342) → 리밸런싱 판단 시 객관화 필요.
