# 김상호 (Kim Sang-Ho)

C 언어 기반 프로그래밍 실전서 저자. 원문에 "저자 金 相 澔"로 표기. "초보와 프로는 종이 한 장 차이보다 작다"는 신념으로 C 언어 실전 성장을 다룬 “아무도 알려주지 않는 프로프로그래머가 되는 길”(도서출판 아이콘, 1995)을 집필.

## 이 wiki에서 확인된 저서
- [[how-to-become-a-programmer]] — 4부 구성(첫 걸음 / 준비 / 프로 흉내 / 프로), VGA·그래픽·압축·게임 등 실전 구현 중심.
- 관련 개념: [[software-quality-cluster]] — 개발자 성장→품질 의식 축.

## 참고
- 원문 참고 문헌에는 "둠(Doom)과 같은 3D 게임 만들기(김상호 역/성안당)", "3D 네트워크 게임 만들기(김상호 역/아이콘 출판사)"의 번역 역자 활동도 기재 — 90년대 중반 게임/그래픽 프로그래밍 전역.
- ※ 이 페이지의 '김상호'는 본 책 단독 저자로, 다른 김상호와 동일인인지 확인 불가.
