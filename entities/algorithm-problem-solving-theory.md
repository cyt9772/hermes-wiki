# 알고리즘 문제해결 — 이론

> 두 번째 입력 예의 경우 입력값 10011000은 첫 번째 비트가 1이므로 음수이고 10진수로 변환하면 152이므로 256 - 152 = 104가 된다. (p20)

## 개요
- **출판:** 한컴에듀케이션 계열(경고) | 310쪽 | text-extract (OCR 재사용)
- **포지셔닝:** BOJ(백준) 문제번호를 기준으로 편성된 알고리즘 문제해결 이론서. 자료의 표현 → 재귀 → 동적계획 → 분할정복 → 데이터구조(스택/큐/트리) → 그리디 → 그래프(BFS/DFS) → 문자열 → 해시 → 정렬/구간트리/긴자리 → 실전 문제까지 16장.

## 내용
- 자료 표현과 진법 변환: 2진수를 10진수로 (1274), 진법 변환 (3106) — 'A'=10, 'B'=11 식 Horner의 법칙을 활용한 계산 예 (p20-22).
- 재귀와 동적계획: 최대공약수/최소공배수 (1002), 하노이의 탑 (1161), 두 줄로 타일 깔기 (1411), 짚신벌레 (1822), 배낭 채우기2 (1278) (p2-3).
- 분할정복과 정렬: 4 3 (SORT/1972), 색종이 만들기 (1335), 타일 (2543), 수열복원 (3111) (p3).
- 데이터구조와 그래프: 스택(1102)·큐(1697)·요세푸스 문제(3101)·이진트리 탐색(1716), 그래프 BFS — 장기(1106), 로봇(1006), 고돌이(2058) (p3-4).
- 구간트리와 실전: 구간의 최대값 구하기 (1726/3238), 긴 자릿수 곱셈(1262), 실전 문제 풀이 (2578 등) (p4).
