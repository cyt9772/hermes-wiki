# Morris E. Levine (모리스 리브)

## 개요
미국 전자공학 교육자. **College of Staten Island (City University of New York, CUNY)** 소속 교수로 『Digital Theory and Experimentation Using Integrated Circuits』(Revised and Enlarged)의 저자. 학부 실험 과정 중심의 디지털 전자학 교과서를 쓴 실무형 교수 — 20개 실험(실험별 "이론 + 실험절차(EXPERIMENTAL PROCEDURE) + 질문" 3단 구조)으로 디지털 논리를 가르치는 체계를 설계한 저자. `^[raw/books/digital-theory-experimentation.md]`

## 활동/저서
- **Digital Theory and Experimentation Using ICs** (297p) — 20개 실험:
  1. Basic Logic Functions (AND/OR 게이트) 2. Boolean Algebra and Simplification 3. De Morgan's Theorem 4. TTL NAND/NOR Gates 5. Exclusive-OR and Applications 6. Full-Adder and Full-Subtractor (4비트 MSI 74183) 7. Bistable or Flip-Flop 8. Binary Counters and Binary Number System 9. Divide-by-N and Decade Counters 10. Shift Registers and Ring Counters 11. Pulse Forming and Shaping; Schmitt Trigger 12. IC Timers — 74122, 74121, 555 13. Decoding and Encoding 14. RAM / Scratch-Pad Memories (64비트) 15. Operational Amplifier 16. D/A·A/D Conversion 17. CMOS: Principles and Characteristics 18. CMOS–TTL Interface + 부록: Astable Multivibrator, FF, One-Shot Schmitt Trigger, Mixers/Modulators, PLL (565), SCR, CRO, 로직 기호, Unit Load
- 2판(Revised and Enlarged) 변경(서문): Exp 1에서 diode 게이트 제거 + TTL 게이트 섹션 추가, Exp 6에 4비트 MSI Full-Adder 도입, Exp 10에 5비트 MSI 시프트 레지스터로 배선 단순화, Exp 11(펄스) 통합, Exp 12(IC 타이머) 신설, Exp 13 7-segment LED 디스플레이 추가, Exp 14 RAM 16→64비트, Exp 17·18(CMOS) 신설, Exp 4 이후 Unit Load 개념 섹션 추가
