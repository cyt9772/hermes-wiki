# 디지털 영상처리 (C) + 실습 (NTSC·Pseudo-NTSC·IIR·FIR·FFT·Edge·DCT·MPEG)

> 원저: 八木伸行·井上誠喜·林正樹·奥井誠人·合志清一 (일본 Ohmsha, 1995)
> 역: 이상길
> 출판: 성안당/Ohmsha(일본), 한국어판 1998, 355p

## 개요
C 언어 중심 **가전·홈비디오 영상처리 실전**. VTR·VCR·전자줌·모니터에 쓰이던 NTSC·Pseudo-NTSC 색신호, IIR/FIR 필터, FFT, Edge 검출, DCT, MPEG 부호화 알고리즘을 C로 구현한다. 일본 Ohmsha 원저의 성안당 한국어 동시출판 `[raw/books/digital-image-processing-c-ki.md]`.

- FIR/IIR 필터, FF Filter, Edge/Noise/Geometric 보정 — VTR·전자줌 실용 알고리즘 [raw/books/digital-image-processing-c-ki.md]
