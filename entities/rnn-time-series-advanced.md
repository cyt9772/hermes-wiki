# RNN과 시계열처리 심화

> 표지: '실무역량 (제4.5판) / (주)한국에이아이연구소 대표이사 홍근선 저' (p1, p2)

## 개요
- **저자:** 홍근선 ((주)한국에이아이연구소 대표이사, gshong@ai-camp.kr) (p4)
- **성격:** 실무역량 교육 교재. Deep Learning 개념을 정리한 뒤 Recurrent Neural Network(RNN)와 그 설계(시계열·Char-RNN·MNIST-RNN)를 심화 다루는 과정 (p6~11, p44). PDF 282쪽.

## 내용
- 구조(차례, p6~14): 1부 Deep Learning 개념 정리(1.1 DL 개요) → 2부 RNN(2.1 RNN Cell Architectures / 2.2 RNN Model Architectures / 2.3 Time Series / 2.4 Char-RNN / 2.5 MNIST-RNN / 2.6 Optimization).
- RNN 아키텍처 실습: Basic Cell부터 RNN Model Design(Time Series)까지, 실제 시계열 데이터셋 위에서의 모델 설계와 최적화를 Keras로 진행 (p44).
- Char-RNN·MNIST-RNN으로 시계열 외 텍스트(MNIST 프레임)까지 폭넓게 RNN을 적용하는 실습 구성 (p44).
- 같은 저자가 쓴 시계열 중심 실습 교재와 연결되는 라인업 (p6~11, p44).
