# Computer Algorithms (C++), Horowitz-Sahni-Rajasekaran

> An algorithm is a finite set of instructions that, if followed, accomplishes a particular task. (p21)

## 개요
- **저자:** Ellis Horowitz(USC), Sartaj Sahni(Florida), Sanguthevar Rajasekaran(Florida)
- **출판:** Computer Science Press (W. H. Freeman) | 1997 | 788쪽 (C++ version)
- **포지셔닝:** C++ 기반 대학원/고학년 알고리즘 교과서. 알고리즘의 정의·성능 분석(공간/시간 복잡도)·재귀적 알고리즘을 1장에서 소개.

## 내용
- 알고리즘의 정의: 유한한 지침 모음으로 입력 0+개·출력 1+개·명확성(Definiteness)·유한성(Finiteness)·실행가능성(Effectiveness) 5요건을 제시 (p21-22).
- 성능 분석: 공간복잡도(Space Complexity)와 시간복잡도(Time Complexity)를 각각 다룸 (p5 목차).
- 실습 권장: '동일 데이터셋으로 두 프로그램을 실행·타이밍하고 결과값을 비교'하는 과제를 가장 교육적이라고 권장 — '알고리즘 실습에는 실무적(Experimental) 측면이 있다'고 강조 (p20).
- 재귀 알고리즘을 1.2절에서 소개하고, 1장에서 성능분석(1.3절)으로 이어가는 구조 (p5).
