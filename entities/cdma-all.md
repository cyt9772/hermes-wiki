# CDMA의 모든 것 (Kim Gap-yong 2002)

> 저자: **김갑용** (Kim Gap-yong)
> 출판: 진한도서 (Jirihan Books INC.), 2002, ISBN 89-8432-087-0, 530p, 정가 24,000원
> 머리말: "우리나라에서 CDMA가 상용화된 지도 벌써 10년을 넘… 한국은 세계 최초의 CDMA 상용화를 성공하였으며, 지금은 2000만이 넘는 사람들이 CDMA 방식의 휴대전화를 사용"

## 개요
**CDMA(코드 분할 다중 접근)** — 한국이 1996년 세계 최초로 상용화한 무선 접속 방식의 원리·기술·산업을 한 권에 담은 실무서. **이동통신방식(제1장)** → **기초 개념(제2장: 상관·직교·규준화, LTI, Fourier)** → **DSSS와 코드 이론(제3장: Walsh/Gold/PN code, IS-95)** → **CDMA 수신기(제4장: PN code 동기, Rake receiver, despreading)** → **전력제어(제5장: closed/open loop, near-far effect)** → **핸드오프(제6장: soft/hard handoff)** → **무선전송기술(제7장: Qualcomm, IS-95, vocoder)** → **호처리(제8장)** → **Vocoder(제9장: AMR, IS-2000/CDMA2000)** `[raw/books/cdma-all.md]`.

## 장 구조 (TOC 기반, 530p)
1. **이동통신방식** — 셀룰러, 기지국-셀, 주파수재사용, PCS, 표준화
2. **Basic Concept** — 상관·직교·규준화, LTI, Fourier 변환
3. **DSSS와 코드이론** — **Walsh/Gold/PN code**, IS-95
4. **CDMA 수신기** — PN code 동기, **Rake receiver**, despreading
5. **전력제어** — closed/open loop, **near-far effect**
6. **Handoff** — soft/hard handoff
7. **무선전송기술** — Qualcomm, IS-95, vocoder, channel estimation
8. **호처리** — call processing, channel assignment
9. **Vocoder** — AMR, IS-2000/CDMA2000
