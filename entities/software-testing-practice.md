# 개발자도 알아야 할 소프트웨어 테스팅 실무 (3rd ed)

**권원일·이현주·최승희·이승호·박은영·조현길(STA)** 6인 공동 집제한 테스팅 실무서, `Test the Best Series` 3판(1판은 2006년). 357쪽. ISTQB 실버 지식 체계를 대부분 번역·편집해 기재하고, 교육·컨설팅(www.sta.co.kr, www.sten.or.kr)에서 체득한 실무 사례를 부가한 형태.

## 장 구성 (원문에 기초)
- **Part 1 테스팅의 기초**: 1장 — 테스팅의 필요성, 결함 원인, 테스팅과 품질, 테스트 프로세스의 기초(계획→설계→구현·실행→리포팅·마감), 테스팅 심리학, 제약 요소.
- **Part 2 소프트웨어 수명주기와 테스팅**: 개발 모델(순차/반복), 테스트 레벨(컴포넌트·통합·시스템·인수), 테스트 유형(기능/비기능).
- **Part 3 정적 기법**: 리뷰 프로세스(공식적 리뷰 단계, 역할과 책임), 리뷰 유형, 도구 기반 정적 분석.
- **이후 Part**: 테스트 설계 기법(리스크 기반, 동등 분할, 경계값, 상태 전이 등), 테스트 관리·리포팅.

## 핵심 3~5개
1. **테스트 프로세스 5단계**: 계획·설계·구현/실행·리포팅·마감. "이 책을 읽는 방법"에서 1.4절을 진입점 삼아 읽어달라고 명시 `[raw/books/software-testing-practice.md]`
2. **리스크 기반 테스팅**: 완결적 테스트가 불가능하기 때문에 리스크 높은 순서로 노력 배분. 5.5절이 책 전체의 방법론적 중핵 — 리스크 아이템을 이해관계자 참여로 결정하고, 그에 따라 기법 선택·자원 투입을 순서화한다.
3. **수준별 테스트 레벨**: 컴포넌트·통합·시스템·인수가 개발 모델에서 각자의 위치를 갖는다는 2장의 축.
4. **정적 기법(리뷰)의 위상**: 3부에서 리뷰(공식적 단계, 역할과 책임, 유형)와 도구 기반 정적 분석을 동적 테스트와 동등한 지위에 올려 놓음.
5. **자격증과 실무의 병행**: ISTQB 실버 지식 체계를 "번역+실무 부가"로 재구성 — 자격 시험 학습서이면서 동시에 실무 모범 답안(솔류션)을 제시한다는 이중 포지셔닝.
