# 혼자 공부하는 머신러닝 / 딥러닝

> 제1쇄 표지: '1:1 과외하듯 배우는 인공지능 자습서' (p3)

## 개요
- **저자:** 박해선 지음 (p3)
- **출판:** 한빛미디어, 초판 2020년 2월 / 3쇄 (p3) | **양:** PDF 578쪽
- **성격:** '혼자 공부하는' 시리즈의 머신러닝·딥러닝 입문서. '어떻게 하면 머신러닝과 딥러닝을 배우기 시작하는 학습자가 더 쉽고 빠르게 익힐 수 있을까'라는 고민에서 출발해, 독자 12명의 실제 학습 결과로 검증된 내용으로 구성되었다 (p5). 설치 없는 구글 코랩으로 즉시 실습할 수 있도록 설계 (p2).

## 내용
- 초심자 대상: 낯선 용어부터 친해지게 해 '완독의 기쁨'을 경험한 뒤 다음 단계를 스스로 선택하게 하는 학습 경로 (p4).
- 실습 중심 워크플로: 학습 데이터셋 분할(트레인/테스트) 실수 사례 — '테스트 세트에 빙어만 들어가 있군요. 확실히 무언가 잘못되었네요' (p74).
- 하이퍼파라미터 튜닝 실습: 결정트리 분류기에 0.0001~0.0005를 0.0001씩 증가하는 5개 값을 `GridSearchCV`로 그리드 서치하며 학습 곡선을 분석한다 — 'GridSearchCV 인스턴스에 탐색 대상 모델과 params를 전달해 그리드 서치 객체를 생성한다' (p249).
- 학습률(alpha) 하이퍼파라미터를 0.001부터 10배씩 증식하며 학습 곡선을 그려 그 행동을 관찰 — 'alpha 값을 0.001부터 10배씩 늘렸기 때문에 이대로 그래프를 그려 보겠습니다' (p163).
