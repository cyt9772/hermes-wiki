# 구글 딥러닝 프레임워크

> 표지: '구글(Google)은 인공지능 기술이 집약된 딥러닝 프레임워크 TensorFlow를 개발했다. 이를 통해 구글은 자율주행 차량, 검색, 쇼핑, 광고, 클라우드 컴퓨팅 등의 서비스에서 데이터 가치를 극대화하여 커다란 상업적 가치를 창출하고 있다' (p1)

## 개요
- **저자:** 정저위·구쓰위 지음, 장우진 옮김 (p1)
- **출판:** 원서 'TensorFlow 2nd ed' (Cai Cloud, ISBN 978-7-121-30959-5) → 한국판: 광문각 (p3) | **양:** PDF 371쪽
- **성격:** Google TensorFlow 프레임워크를 예제로 풀어보는 실전서. 예제 기반(Hands-on) TensorFlow 사용법을 다룬다 (p1~2).

## 내용
- 챕터 구성: Chapter 01 '인공지능·머신러닝·딥러닝 개요 → 딥러닝의 발전 과정 (p8) → 응용 (p9~10) → 컴퓨터 비전 (p11~)', 'Chapter 04 딥러닝과 심층 신경망 (p106)', 'Chapter 06 이미지 인식 문제와 데이터셋 (p98)' 등 순으로 구성 (p10~13, p14).
- 특징 벡터 기반 학습: '쓰인 모든 숫자의 조합을 특징 벡터(feature vector)라고 한다. 1장에서 설명했듯이' — 특징 표현 → 모델 학습 흐름 (p78).
- 산업 적용 관점에서 구글 생태계(자율주행, 검색, 쇼핑, 광고, 클라우드)와 TensorFlow의 관계를 다룬다 (p1).
