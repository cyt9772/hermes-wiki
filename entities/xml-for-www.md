# XML For the World Wide Web

Elizabeth Castro 저, Peachpit (Addison-Wesley Longman, 미국) 2001 원서. 한국어판: 비앤비 (B&B), KCC 독점계약, 2001-02 펴냄. **Visual QuickStart Guide 시리즈 — XML을 웹 문서·스타일링·변형에 적용하는 실무 입문서.**

## 인용 (책 말미)
> "XML이라는 언어는 처음에는 많은 주의를 필요로 하지만 더욱 좋은 결과물을 만들어 내는 특징이 있다. 말하자면 HTML이 모든 사람에게 자그마한 혜택을 주었다면 XML은 소수의 사람에게 풍성한 혜택을 주었다고 할 수 있다."

## 내용 (Visual QuickStart Guide 구성)
- 0. XML 도입 + 이 책의 범위 (DOM/SAX/SOAP/XML-RPC/JS/ASP는 **배제**)
- 1. XML 작성법 — 요소·속성·가치값, 중첩, 빈 요소, 주석, 특수 5기호, DTD
- 2. XML 스키마 — DTD 대안, 타입 시스템
- 3. XSLT/XSL — 스타일 변환, HTML/CSS 출력
- 4. XML + 웹 — ASP·JSP·JDBC 연결 (개념 소개 수준)
- 5. Web Services 개념 — SOAP 구조 (개념)
