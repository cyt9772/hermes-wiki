# 깡샘의 안드로이드앱 프로그래밍 (코틀린)

> 세상의 속도를 따라잡고 싶다면 (p1)
## 개요
- **저자:** 강성윤
- **쪽수:** 741p (텍스트 레이어 추출, 로컬 PDF `/run/media/yutae/Data/깡샘의 안드로이드앱 프로그래밍.pdf`)
- **위치화:** '세상의 속도를 따라잡고 싶다면' — Do it! 시리즈의 안드로이드 앱 개발서. 개정 4판(2025.2)으로 안드로이드 API 레벨 35 기준 (p1, p3).
## 내용
- 개발 환경: '안드로이드 5 버전 · API 레벨 35' 기준으로 구축 (p1).
- 코틀린 기본: '이 if-else 문은 대부분의 프로그래밍 언어에서 제공하는 조건문과 차이가 없습니다' — 하지만 코틀린에서는 'if-else를 표현식(Expression)으로도 사용할 수 있습니다' (p101).
- when 조건문: '코틀린은 if-else 문 말고도 when이라는 조건문을 작성할 수도 있습니다' — `when(data) { 10 -> ... 20 -> ... else -> ... }` 형태로 값을 분기 (p102).
