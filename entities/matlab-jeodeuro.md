# 제대로 배우는 MATLAB

> 저: **방성완**
> 출판: 한빛아카데미, 2014 (5쇄 2019), 426p, ISBN 979-11-5664-134-8

## 개요
MATLAB을 전공 실습에 바로 쓰도록 **기본 + 핵심 + 활용**을 한 권에 담은 입문서. 명령창·편집·변수·행렬 연산·그래픽화·스크립트/함수 작성부터 Signal/Image/Signal-Processing Toolbox 실습까지, "바로 찾는 MATLAB"을 지향하는 실용 교재 `raw/books/matlab-jeodeuro.md]`.

## 핵심 내용
- 명령창·워크스페이스·변수·행렬·문자열 기초와 수치/심볼릭 연산 `raw/books/matlab-jeodeuro.md]`
- 2D/3D 그래픽화, 스크립트·함수·조건/반복 제어문으로 프로그램 작성 `raw/books/matlab-jeodeuro.md]`
- Signal · Image · Symbolic Toolbox 실습으로 전공 연동 (DSP/영상/심볼릭)
- 방성완 저자의 후속 확장서 [[matlab-simulink-jeodeuro]](2020)의 전 단계
