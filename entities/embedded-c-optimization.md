# 임베디드 프로그래밍 C코드 최적화

> 표지·프러포즈: "블로그에서 읽는 듯한 생생한 개발 노하우!" (p1)

## 개요
- **Author:** 김유진 저 (IDS 테크놀로지지 출신, 임베디드/자바 개발·강의)
- **Publisher:** 한빛미디어
- **Pages:** 278
- **Positioning:** 블로그 스토리(김 대리·박 과장) 형식의 임베디드 C 소프트웨어 개발·최적화 실무서. "적은 비용으로 최대 효과를 내는 시스템 개발" (p3).

## 내용
- 크로스 개발: "크로스 개발에서 소프트웨어를 개발하는 환경을 호스트 시스템, 소프트웨어가 실행되는 시스템을 타겟 시스템이라고 한다" (p19).
- 툴체인: "크로스 컴파일러, 크로스 어셈블러, 링커／로케이터 등으로 구성된 소프트웨어 개발도구를 말한다" (p20).
- 스타트업 코드: "인터럽트 벡터 테이블을 생성하고, 메모리 검사와, C 프로그램에서 사용할 스택과 힙을 생성하고 초기화하는 등 C 프로그램이 작동하기 위한 초기화 작업을 수행한다" (p23).
- main()의 위치: "main()은 시스템의 시작점이 아니다 / 시스템의 동작은 크게 초기화 작업과 프로그램 실행으로 나누어 볼 수 있다" (p71).
- 메모리 관리: 임베디드 개발환경에서는 `malloc()`을 지원하지 않는 경우가 많아 "직접 힙에 접근해서 원하는 만큼의 메모리를 할당 받아 사용한다" (p74).
