# 좋은 프로그램을 만드는 핵심 원리 25가지

**김종훈 · 김종진 · 정원희 · 정은영** 4인 지음, 한빛미디어 2003년 1월 초판(제179호). 529쪽. 단체 저자(4인)이므로 개별 author entity를 두지 않는다. "알고리즘의 원리를 통해 좋은 프로그램을 만든다"는 컨셉으로 25가지 핵심 원리(각 장 하나의 알고리즘/원리)를 실습 중심으로 풀어 쓴 프로그래밍 입문~중급서.

## 구조 (원문에 기초)
- 25개 장(원리) 각 하나씩: 수열(재귀 호출), 난수, 오류 검출, 배열, 그래프(차량 자동 경로) 등 — 각 원리가 일상·공학 문제에서 어떻게 쓰이는지를 "원리 소개 → 프로그램 구현" 흐름으로 전개 `[raw/books/good-programming-principles-25.md]`
- 예: "재귀 호출의 원리는 수열", "예측 불가 게임 캐릭터의 좌충우돌 동작 원리는 난수", "네트워크가 스스로 오류를 검출하고 정정하는 원리", "차량 자동 경로 탐색 시스템의 기본 원리는 그래프 이론"
- 자료실 코너에 소스 제공, 홈페이지에서 원리 응용 예제 제공.

## 핵심 3~5개
1. **"원리 = 알고리즘"의 프로그래밍관**: 문법 암기가 아니라 문제에 대응하는 알고리즘 원리를 체득하는 것이 좋은 프로그램의 전제 — 머리말의 지향점.
2. **실습 중심 전개**: 각 원리를 C/프로그래밍 실습으로 구현(재귀, 난수, 오류 검출, 배열, 그래프 등). "이론을 제대로 이해하는 것도 필요하지만, 이 이론을 프로그래밍에 적용하는 방법을 아는 것도 중요하다"는 저자 서문의 원문 문장.
3. **입문~중급의 교량**: 교육 현장(컴퓨터교육, 과학영재 교육)에서 쓰이도록 이론과 교수법 사이의 간격을 메우는 서적 — 저자 4인 모두 제주교육대·홍익대/가톨릭대 계통의 교육·연구자.
4. **일상 문제→알고리즘 매핑**: "재귀의 원리는 수열", "게임 캐릭터의 좌충우돌은 난수", "네트워크의 스스로 오류 정정(자기 정정) 원리", "차량 자동 경로는 그래프" — 원리를 일상/공학 문제에서 역추적하는 서술 방식.
