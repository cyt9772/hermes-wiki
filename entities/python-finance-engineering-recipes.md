# 파이썬을 활용한 금융공학 레시피

> 표지: '문과생의 코딩 울렁증과 이과생의 금융 울렁증을 한방에 씻어줄 금융공학 사이다' (p1)

## 개요
- **저자:** 김용환 지음, 장민자·노태협 감수 (p3)
- **출판:** 한빛미디어(주), 초판 2018-06-01, 초판 4쇄 2021-02-19, 401쪽 (p3)
- **성격:** 파이썬(NumPy·Pandas)으로 주가 데이터 처리, 선물·옵션 가격 이론, 금융공학 기초를 '레시피' 형식으로 풀어가는 입문·중급 실전서 (p1, p3).

## 내용
- NumPy 배열 인덱싱: 'v[1, 2] # 2행 3열 데이터 추출 → 23', 'v[:, 1] # 전 행, 2열 데이터 추출' 등 2차원 배열 슬라이싱·추출 기초 (p198).
- Pandas 데이터프레임: ' 넘파이에서는 하나의 배열에 동일한 형태의 데이터만 담을 수 있지만, 판다스는 하나의 데이터프레임에 다양한 데이터를 집어넣고 쓸 수 있다는 차이가 있다. 또한 팠다스에서는 인덱스를 이용해 데이터를 조작할 수 있다는 장점이 있다' — 날짜 인덱스 활용 예제 (p199).
- 스프레드시트형 데이터 처리: '팠트스를 이용하면 파이썬의 자료 구조를 엑셀의 스프레드시트와 같은 형태로 만들어 대용량 데이터를 쉽게 처리할 수 있다. 그뿐 아니라 팠트스는 스프레드시트 형태의 데이터를 데이터베이스처럼 사용할 수 있게 해서' (p200).
- 파이썬 기초 부록: 리스트 `append`·`remove`·`extend`·세트(집합) `∪`(합집합), `∩`(교집합), `-`(차집합) 연산 등 기본 자료구조·연산 정리 (p392–393).
