# 황선규 (Hwang Sun-gyu)

한양대학교 영상 처리 전공 박사(2006). 재학 시 연구 분야: 객체의 모양 기술, 객체 분할, 패턴 인식; 2007년경 뉴질랜드 캔터베리 대학 HITL(Human Interface Technology Lab)에서 마커리스 증강 현실(MagicBat) 프로젝트·마커 없는 증강 현실 연구 수행. 귀국 후 한양대 영상 공학 연구실 연구교수; 현재 연구 분야는 실시간 특징점 정합과 3차원 모델 기반 객체 추적 `[raw/books/image-processing-programming-visualc.md]`.
