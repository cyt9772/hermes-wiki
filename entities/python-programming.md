# 실전 예제로 배우는 파이썬 프로그래밍

> '파이썬 프로그래밍과 빅데이터 분석을 위한 최고의 기본서' — 4차 산업혁명 기조 아래 파이썬 언어와 빅데이터 분석 기초를 실전 예제로 다룬 기본서 (p1)
## 개요
- **Author:** 김진성 (지은이, p355)
- **Publisher:** 제이비김영 (JBI Kyoung, p355) | **Pages:** 357
- **Positioning:** 빅데이터 분석을 목적지로 한 파이썬 기초 교재. 파이썬 3.7 + PyCharm 2019.2.1(Community) 실습환경 기준 (머리말, p3-4).
## 내용
- 머리말: 4차 산업혁명 환경에서 파이썬이 '신속하고, 유연하게 프로그램을 개발할 수 있는 도구로 급부상'했으며, 본서가 '빅 데이터 분석을 목적으로 한 파이썬의 기본서'임을 밝힘 (p3).
- 구성: 프로그래밍 기본문법, 자료구조, 라이브러리, 객체지향, 정규표현식, 파일 자료처리, 자료수집&처리, 데이터베이스 자료처리 8가지 영역으로 순서를 두었다 (p3-4).
- 모듈/패키지 실습: `import 최상위패키지.하위패키지.모듈`과 `from ... import 함수` 두 가지 방식으로 산포도(분산·표준편차) 함수를 호출하는 예제 (p178).
- 가상환경과 패키지: PyCharm 프로젝트 폴더 지정 시 `venv` 가상환경이 자동 생성되며, numpy·pandas·PyMySQL 등 패키지 설치 화면을 통해 가상환경 관리법을 실습 (p238).
- 실습환경: D드라이브 `Pywork` 공통폴더 아래 `tools`(다운로드 파일 보관)와 `workspaces`(프로젝트 폴더)를 나누는 폴더 구조 제시 (p4).
