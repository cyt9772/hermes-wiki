# PERFECT WRITING

> "토플 채점관과 미국 교수들이 말하는" — TOEFL 에세이 + 대학 작문. 총 10장. `[[english-grammar-patterns]]`(논리적 작문) + writing process.

## 개요
- **Title:** PERFECT WRITING
- **Authors:** Valerie De Carvalho (UCLA, TESL MA, LusoBrazilian Languages MA), Marc Handler (TOEFL 채점관)
- **출판:** Freelec USA (2000)
- **쪽수:** 567
- **핵심:** "Writing이 지금 미국 대학의 시작이면서 끝이다" (p5)

## 10장 구조 (p11 "책의 전체 구성" 근거)
| 장 | 내용 |
|---|---|
| 1–4 | TOEFL 에세이 + 대학 에세이 개요, 주의점, 시험 대비책. 에세이 종류별 좋은 에세이 정의·작성법 |
| 5 | 문법을 바탕으로 짧은 단문장 → 문장 연결 → 문단 전개 (외우는 문법이 아닌 **이해하는 문법**) |
| 6–7 | 작문의 개념, 미국식 논리적 작문. 한국 문화·한국인을 예제로 |
| 8–9 | 실제 학생 샘플 에세이 기반 **교정과 수정 기술**, 평점 기준 |
| 10 | 자주 헷갈리는 단어 비교 정리 + 문장 내 활용 예제 |

## 특징
- **교수 직접 첨삭**: 에세이를 www.writinglecture.com에 제출 → 미국 명문대 현직 영문과 교수가 평가·수정 (p11, p15–16).
- **평점 기준**: "A passing essay has at least 350–450 words and demonstrates appropriate use of introductory, body, and conclusion" (p482).
- **메타포(은유) 활용**: Description → Metaphor 전환으로 문체 개선 (p380–382).
- **논리적 구성**: thesis(주장) + supporting reasons 구조 (p19).
