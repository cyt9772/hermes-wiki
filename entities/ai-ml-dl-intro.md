# 인공지능·머신러닝·딥러닝 입문

> "결국 구글의 인공지능 컴퓨터는 10년 이상 (바둑계를) 평정했던 바둑 천재 이세돌 9단을 4 대 1로 물리치며 서울발 인공지능 쇼크의 진원이 됐다." (p12)

## 개요
- **Author:** 김의중 지음 (데이터사이언스 시리즈 7)
- **Publisher:** 국내 판 | **Pages:** 352
- **Positioning:** 알고리즘 관점에서 AI→ML→DL로 올라가는 개념 입문서. 01부 '알파고와 구글 딥마인드', 02부 '머신러닝'으로 이어지며 튜링 테스트·퍼셉트론·AI의 두 번의 겨울 같은 역사 서술로 시작한다 (p4).

## 내용
- AI의 역사: 앨런 튜링과 튜링 테스트, 최초의 인공신경망 퍼셉트론, 인공지능의 첫 번째·두 번째 겨울과 재도약, IoT 시대의 AI까지 연대기적 개관 (p4).
- 2011년 IBM 왓슨이 '제퍼디!' 퀴즈쇼에서 인간 역대 최강 후보를 압도한 사례로 AI의 비약적 발전을 서술 (p12).
- 알파고 대 이세돌(2016.3.9~15): "인류의 달 착륙" — 딥마인드 CEO 데미스 하사비스의 비유 (p13).
- 머신러닝의 정의: "사전에 정의된 절차나 사용자가 그때그때 매개변수를 변경해서 데이터를 분석하는 방식 대신 학습 프로세스 규칙을 만들어 사용자가 컴퓨터를 직접 학습시켜 분석하는 범용적인 분석 모델" (p87).
- 지도학습 예: 세포 형태학(HeLa 세포)에서 metaphase/interphase 레이블 학습 후 새로운 데이터의 세포 분열 단계 예측 (p87).
- 강화학습: 알파고의 학습 모델. 행동심리학의 '시행착오'와 최적 제어(리처드 벨먼의 동적 계획)에서 유래하며, 환경의 보상·벌칙 피드백으로 학습해 세 번째 머신러닝 모델로 분류한다 (p88~89).
